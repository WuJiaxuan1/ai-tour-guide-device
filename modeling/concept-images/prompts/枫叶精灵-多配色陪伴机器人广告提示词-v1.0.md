# 枫叶精灵 v1.0｜多配色陪伴机器人广告提示词

使用方法：将 front-v1.0.png、side-v1.0.png、back-v1.0.png 一起作为图像参考上传，再复制下方提示词。三张图片对应同一款角色的三个视角。下述动作与界面属于广告创意设定，不作为硬件功能验收记录。音乐为可选参考，没有上传音乐时使用文中的默认配乐要求。

【生成目标】
为“枫叶精灵”制作一条高端陪伴机器人产品发布广告。它是一位小巧、温暖、有表情的随行伙伴，能够回应陪伴、提供导航指引，并以简洁的屏幕表情传达情绪。整体气质亲切、灵动、可靠，兼具收藏级角色的可爱感与精密电子产品的真实质感。

全片在同一个极简纯白无缝摄影棚内展开，采用写实产品摄影与高品质三维角色动画质感。以枫红色主角贯穿前半段，通过微距运镜依次展示外壳细纹、枫叶饰件、圆形表情屏、侧边按键和背部孔位，再展示倾听、回应、导航与挥手互动，最后拉远揭示六种真实秋季枫叶色系的枫叶精灵。

采用视觉连续的一镜到底，摄影机沿角色外部掠行、升降、环绕、推进与拉远。通过精细材质、清楚视差、微距与全身的尺度变化、流畅变速形成高级产品广告观感。主角的动作幅度小而自然，具有小机器人的重量感和可爱节奏。

【参考素材职责】
参考图 front-v1.0.png：角色身份和正面造型的主参考。严格保留圆润尖顶的红色兜帽、向肩部两侧展开的披风轮廓、画面右上方的立体橙色枫叶饰件、嵌入深灰边框的黑色圆形表情屏、奶白色身体、短圆手臂和两只短脚。保留正面画面左侧黄色按键、右侧蓝色按键，以及屏幕边框上方和下方的原有开孔位置。发光表情沿用暖白色圆点眼睛和弯弧微笑的设计语言。

参考图 side-v1.0.png：定义兜帽与屏幕的前后厚度、屏幕外凸弧面、侧边按键位置、枫叶饰件厚度、披风下摆和短手臂的遮挡关系。摄影机绕行时必须符合该侧视图，不把正面图当作平面贴片旋转。

三张图共同定义同一个三维角色，不能分别生成三种造型。枫叶饰件始终固定在角色自身左侧、正面画面右上方；转到背面后，它自然出现在画面另一侧，不发生镜像换位。

【材质与造型】
兜帽和披风表现为具有细腻微纹理的哑光软触外壳，轮廓饱满，边缘柔和，保持参考图中的成型结构。奶白色身体具有细微触感纹理；枫叶饰件有清晰的叶裂轮廓、简洁叶脉起伏和温润高光。圆形面屏为深黑色弧面玻璃，保留克制的摄影棚柔光反射，表情清晰可读。边框为深灰色，按键保留独立实体厚度。

角色没有真实眼球、嘴巴、牙齿、毛发或动物耳朵。眼睛、微笑、倾听状态和导航信息均是同一块黑色圆形屏幕上的二维发光图形。屏幕表面和边框保持稳定，不随表情变形。

【真实枫叶色系与多配色规则】
全片出现六款同造型、同尺寸、同材质的配色版本。配色灵感来自真实枫叶在秋季呈现的深红、红、橙与黄色及其相邻色系，颜色自然、温暖、有层次。

1. 枫红款：参考图中的温暖枫红色兜帽披风，橙色枫叶饰件；作为主角贯穿全片。
2. 深红款：成熟枫叶般的酒红、绛红色兜帽披风，铜橙色枫叶饰件；暗部仍能看到材质纹理。
3. 赭橙款：带少量红棕调的深橙色兜帽披风，金橙色枫叶饰件。
4. 橘色款：明亮而不荧光的橘橙色兜帽披风，偏红橙色枫叶饰件。
5. 琥珀黄款：温暖、略带橙调的琥珀黄色兜帽披风，赭橙色枫叶饰件。
6. 金黄款：明亮柔和的金黄色兜帽披风，枫红色枫叶饰件。

配色变化集中于兜帽披风和枫叶饰件。六款均保留奶白色身体、黑色面屏、深灰边框、暖白色表情，以及参考图中的黄色和蓝色小按键。小按键是固定的识别细节，不扩展成蓝色主题配色。

每款以一个稳定的主色为基础，通过真实光照产生深浅变化，不使用彩虹拼色、霓虹色、金属电镀色或透明果冻材质。六款是六个独立实体，入镜后颜色固定，不能把主角连续变色来代替多配色同框展示。

【摄影与空间连续性】
摄影机始终在角色身体外部移动，依次经过面屏、兜帽、枫叶饰件、侧面按键、背部外壳、正面表情、胸前和手臂，最后退至全景。

微距段落中，兜帽边缘、枫叶饰件或手臂经过前景，后方身体部位提供空间定位。近景移动较快，远景移动较慢，形成自然视差。玻璃反光随摄影机位置合理变化，表情图形固定在屏幕显示平面内。

每段运动按“加速接近—减速观察—顺势离开”组织，关键细节与功能状态出现后留出辨认时间。保持统一的光源方向、地面接触阴影和空间关系。隐藏衔接仅发生在实体完全遮满画面时，不穿过屏幕、兜帽或身体。

【连续事件】
第一阶段：从屏幕微距唤醒，建立陪伴感。
从黑色弧面屏幕边缘与深灰边框的极近特写开始。摄影机低角度沿边框侧向掠行，前景掠过兜帽的细微纹理，暖白色的一只圆点眼睛逐渐进入画面。
摄影机减速，焦点落在面屏表情与玻璃反射上。屏幕上的两只眼睛由轻闭弧线睁成圆点，随后出现参考图中的弯弧微笑。
摄影机后退并略微上升，逐渐揭示完整面屏、红色兜帽和枫叶饰件。主角面向镜头，做一次轻微的身体前倾，像是在温柔地打招呼。

第二阶段：沿兜帽上升，环绕枫叶饰件。
承接上升运动，摄影机沿兜帽弧面斜向靠近角色自身左侧的枫叶饰件。红色外壳纹理在前景经过，橙色叶片逐渐占据近景。
摄影机沿叶片边缘由下向上移动，再做短弧线绕行，展示叶裂轮廓、叶脉起伏、厚度和与兜帽接触处的阴影。黑色面屏与红色兜帽留在后方，形成明确纵深。
枫叶饰件保持固定，具有真实成型材质的体积，不像真实叶子一样飘动，也不变成耳朵或翅膀。柔和轮廓光轻轻描出叶片边缘。

第三阶段：沿侧面绕到背部，展示产品实体结构。
摄影机从饰件顺势下降至侧面，经过蓝色实体按键，展示面屏弧度、边框厚度、兜帽包覆关系与短圆手臂。
继续沿同一方向绕向背面，短暂减速，清楚展示参考图中的背部孔位、分件线、圆润外壳和披风后摆。随后继续绕到另一侧，经黄色按键回到正面。
角色稳定站在原地，身体不会跟随摄影机同步自转。背部孔位、饰件位置和按键左右关系在整个环绕中保持一致。

第四阶段：倾听与回应，展示情绪陪伴。
摄影机回到正面头肩构图，慢慢靠近。轻微的画外提示声响起，主角的屏幕眼睛向声源方向偏移，再变成专注的短弧形眼睛；身体向声源方向轻轻倾斜。
屏幕下方短暂出现三个柔和起伏的小圆点，表达正在倾听。小圆点消失后，双眼变为开心的弧线，弯弧微笑略微展开。
主角做一次幅度很小的点头式身体前倾，再回正，配合两声柔和电子回应音。情绪变化完整发生在屏幕图形和轻微姿态中，实体外壳保持原有形状。

第五阶段：简洁导航，表达“陪你一起走”。
摄影机保持能完整看清面屏的近景。表情平滑淡出，同一块圆形屏幕切换为简洁导航界面：一个暖白色当前位置圆点、一小段路径线、一个明确的向右转弯箭头，以及终点标记。
路径线从当前位置向前延伸后向画面右侧转弯，当前位置圆点沿路径缓慢移动一次。图形线条清晰、数量克制，不出现复杂地图、路名或数字。
主角用自身左侧、也就是正面画面右侧的短圆手臂轻轻抬起，向屏幕箭头所指的方向示意。手臂不长出手指，不伸长，不变成机械抓手。
导航状态保留足够的辨认时间后，屏幕恢复暖白色微笑表情；手臂保持轻抬，为下一段挥手自然衔接。

第六阶段：挥手慢动作，展示灵动互动。
摄影机下降并靠近刚才抬起的同一只手臂。主角完成一次小幅度挥手，手臂保持圆润简洁，动作从肩侧自然发生，双脚稳稳接触地面。
挥手中段短暂放慢，音乐正常推进。摄影机以手臂为观察中心，从斜前方沿短弧线绕向侧前方，展示奶白色手臂纹理、披风边缘和后方面屏的视差。
主角的屏幕眼睛变成开心弧线。摄影机完成短弧线绕行后，挥手恢复正常速度，手臂自然回落。

第七阶段：顺势拉远，揭示秋叶色系家族。
摄影机跟随回落的手臂经过披风下摆和奶白色身体，再连续后退并上升，从局部细节拉开为完整站姿。
随着视野逐渐扩大，原先位于画外的另外五款枫叶精灵依次进入画面。它们此前已站在同一摄影棚的更宽区域，通过扩大取景自然显露，不凭空复制，不从主角身体分裂，也不通过变色生成。
最终六款形成疏朗的浅弧形站位，枫红主角稍靠前，其余五款分列两侧，深红、赭橙、橘色、琥珀黄和金黄都能清楚辨认。各款轮廓和枫叶饰件不互相遮住，脚下有独立、方向一致的接触阴影。
六款保持相同的头身比例、屏幕尺寸、短手短脚和饰件位置。用少量不同表情赋予个性：微笑、眨眼、开心弧线眼、专注圆点眼；保持统一的暖白色图形语言。

第八阶段：稳定全景，留下陪伴记忆。
摄影机缓慢调整到略高于面屏中心的正面全景并停稳。六款占据画面中部偏右区域，左侧留出干净的纯白空间，整体像一组精致的产品发布主视觉。
枫红主角向镜头轻轻挥手一次，其余角色以错开的细小眨眼和轻微身体倾斜回应，避免整齐划一地同时摆动。随后全部稳定站好，以微笑面向观众。
跟随音乐收尾保持全景，让圆形表情屏、兜帽上的枫叶饰件与从深红到金黄的六款配色成为最后的视觉记忆。

【声音与节奏】
如上传音乐参考，使用其原有节奏推进与收尾组织运镜，不改变原曲内容，也不额外续唱。如未上传音乐，使用温暖、轻盈、精致的无歌词电子配乐，以柔和木琴或轻拨弦音色衬托陪伴感。
屏幕唤醒、倾听回应、导航确认分别配合简短柔和的电子提示音。挥手与摄影机掠行可搭配少量轻微空气感音效，不使用夸张机械撞击声。
慢动作期间音乐正常推进，动作恢复时与清楚的节奏落点呼应。不额外生成人声旁白、对白或演唱。

【保持一致】
严格遵循 v1.0 三视图中的角色，不混入其他版本造型。前半段只有同一只枫红主角，后半段通过拉远展示六个固定配色的独立角色，最终总数为六个。
每个角色始终只有一块黑色圆形面屏、一枚固定位置的枫叶饰件、两只短圆手臂和两只短脚。保持外壳厚度、边框结构、按键、开孔、分件线和披风下摆一致。
表情和导航图形局限于面屏之内，不漂浮到空气中，不投射成全息界面，不延伸到外壳上。每次只显示一个清楚的主要状态，保证观众能够读懂。
动作采用轻微整体倾斜、自然回正和短手臂摆动，不增加可见关节，不伸长四肢，不让兜帽与身体脱离，不将披风变成飘动布料。
统一纯白摄影棚、柔和主光、自然轮廓光与接触阴影。奶白色身体在白背景中仍有清晰边界，深红款暗部保留细节，黄色款保留层次，黑色面屏不过曝。
生成画面中不出现文字、标题、字幕、数字、标牌、Logo或水印。允许出现明确要求的屏幕表情、倾听圆点、导航路径、箭头与终点符号。

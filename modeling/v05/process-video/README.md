# v05 建模过程演绎 · 5 秒

- 成片：`v05-modeling-process-5s.mp4`，1920 × 1080，30 fps，150 帧，无音轨。
- 动画工程：`v05-modeling-process-5s.blend`。打开后默认停在成品；将时间轴移到第 1 帧，播放到第 150 帧即可查看模型变化。
- 画面来自 Blender 自带截图功能对真实工作窗口的逐帧截取，保留工具栏、物体列表、属性栏及时间轴；没有拼造软件界面。
- 中间体块和开孔过程为按建模逻辑重建的演示，不是原始操作历史录像。
- 最终外壳和前圈来自上一级 `assembly-snap-v05.blend`。动画中仅将模型整体抬高 74 mm，让脚底对齐工作平面；最终外壳形态键归零，保留源模型的最终网格。
- 设备及屏幕仅用于装配示意。这份动画工程包含演示体块，不用于制造或打印。

## 节奏

1. 第 1–37 帧：从空场景到身体、手脚、头部基础体块。
2. 第 38–64 帧：帽尖塑形，添加披肩。
3. 第 65–95 帧：细化为 v05 外观，逐渐打开设备容纳口并形成枫叶浮雕，显露内部支撑。
4. 第 96–124 帧：参考设备由正面放入，前圈装入。
5. 第 125–150 帧：完整模型小幅转动。

## 重建

使用本机 Blender 执行 `scripts/build_process.py` 建立独立动画工程；再以可见窗口打开工程并执行 `scripts/capture_interface.py`，最后后台执行 `scripts/encode_video.py`。截帧过程请保持 Blender 窗口布局不变。

所有截图和编码中间文件位于项目 `.local-work/v05-process-video/`。原 v05 工程、STL 和打印交付文件不作修改。动画工程在普通播放时使用固定视口；成片末尾的小幅转动由截图脚本同步已有相机关键帧到视口完成。

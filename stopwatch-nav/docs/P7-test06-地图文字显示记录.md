# P7-test06 地图文字显示对比（2026-10-29）

用户认可地图缩放 14.0，反馈地名/标志尺寸太大。本版本只改 Android APK（versionCode139，versionName8.3.26-p7-test06），沿用 P7-test04 固件和 P7-test05 的缩放值。覆盖安装不清除应用偏好。

- 高德地图显示 API 是二值 `showMapText`，没有此 SDK 图层的独立字号缩放档位。App 增加“标准”和“隐藏地图文字”选择；清爽档对高德调用 `showMapText(false)`，道路几何保留。地图版权标识不去除。
- 保存档位并请求新截图；截图请求和 `MapPixels` 标记所用档位。上传已开始时不取消，完成后若与当前选择不同则继续请求最新图；显示“手表已应用/等待更新”避免误判。原选定地图缩放 14.0 不变。
- 不宣称可隐藏所有独立 POI 图标。真机若仍有图形标志，请用户告知是文字还是图标，再按高德 SDK 可用自定义地图样式评估下一步；不做会损坏底图道路的像素擦除。

验证：`tools/build.ps1 -Target android -Offline -Test` 成功，32 项 JVM 测试通过；P7-test05 同签名/包名、启动 Activity 和版本信息校验通过。离线构建不证明 SDK 真机文字层结果，需用户验收。

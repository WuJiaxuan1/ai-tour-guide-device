## 更新后的效果

- 开机仍按原流程配置网络，配网、激活和错误说明仍有文字。
- 配网完成并进入待机后，语音页全屏显示黑底白色眼睛，上下文字、字幕、IP、音量和切页提示都不显示。
- 待机：自然眨眼、呼吸和转动视线；唤醒后：侧头聆听；收到识别结果等待回复时：思考；小智回答时：眼睛轻微起伏和歪头。
- 云端发来情绪消息时，可显示开心、兴奋、好奇、困惑、生气、惊讶、伤心、困倦和眩晕，播完回到当前对话状态。
- 保留左右按键、左右滑动切页、导航页暂停语音、地图块与定位、路线与已走路线变色。
- 保留每次开机配网、原绑定数据和开机音量 85。

说话动作跟随小智的“开始/结束回复”状态，不是逐字或按声音大小同步。思考状态从已有 STT 识别结果触发，云端回复很快时可能只出现很短时间。云端不保证每次回复都发指定情绪；没有某个表情不一定是故障。

将手表通过可传数据的 USB 线接到电脑，关闭占用串口的软件。把下面的 `COM实际端口` 换成当前端口，例如 `COM3`：

```powershell
Set-Location 'D:\Study\yiqifen\stopwatch-nav\releases\P8-avatar-test01'
& 'D:\Study\yiqifen\stopwatch-custom\.tools\espressif\python_env\idf5.5_py3.12_env\Scripts\python.exe' .\flash_p8.py --check-files
```

脚本先核对包文件、分区表和当前应用槽，再写应用与对应资源并回读校验。不擦除整片 Flash、不写 NVS、分区表或 OTA 选择数据。这样沿用原有小智绑定；实际云端绑定仍请按下表确认。旧 `.venv-flash` 的 Python 启动器当前不可用，因此此处改用已经验证可运行的 ESP-IDF Python 环境。

如果脚本报错，保留完整报错并停止，不使用整片擦除。无需重新安装 App。

## 代码与验证记录

新增 `avatar_engine.*`、`avatar_surface.h`、`avatar_display.*`，移植原 Avatar 的关键帧、眨眼、视线和绘制逻辑，并通过 LVGL 图层接入语音页。每帧只让变动区域重绘；额外 RGB565 画布为 434,312 字节，设备上从 PSRAM 分配。目标调度为每 40 ms 一次，约 25 次/秒，不代表已经测得的设备帧率。地图页暂停动画。

原项目的触摸表情、IMU 摇动和按钮浏览表情不接入，避免干扰已有导航操作。小智应用状态机、音频流程和网络协议没有改动。

自动检查包括：渲染越界与残影、眨眼闭合/张开、短暂情绪回落、文字遮挡、恢复原配网页、地图页暂停和反复切页、原地图/定位/路线/已走进度像素测试、HTTP 协议、唤醒模型与资源、分区与回退包一致性。

`build-report.json` 记录文件哈希和真实验证状态；`source/` 为相关源码快照；日志和电脑渲染预览一并附带。预览不是实机照片。

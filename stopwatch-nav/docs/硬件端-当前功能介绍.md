# 栖霞山枫叶精灵｜硬件端当前功能

2026-10-30 · P8-test02 · 用户确认最新版本全部测试通过。

## 已实现

- **语音终端**：StopWatch 通过手机热点连接小智云端，支持“枫叶精灵”唤醒及语音对话；保留原智能体绑定，开机音量85，每次开机重新配网。
- **双页操作**：按键或左右滑动切换语音页、地图页；地图页暂停语音。
- **周边地图**：手机 GPS＋高德地图，显示当前位置；地图铺满圆屏，支持缩放、隐藏文字、预取地图块和移动窗口。
- **步行路线**：手机选择目的地并通过高德算路，路线与底图分开传输，手表显示道路折线和终点。
- **已走变色**：手机计算路线进度，手表把走过的前缀改为已走色；回走、失去 GPS 不抹掉已确认进度，调色和地图换块保留进度，重规划清零。
- **参数调试**：手机可设置未走/已走路线、定位点、终点、描边颜色和线宽，并保存。常用地图缩放14.0、隐藏文字。

## 各部分如何配合

```text
语音：游客 → StopWatch → 手机热点上网 → 小智云端 → StopWatch 播放回答
地图：Android GPS＋高德 SDK → 地图块/位置/路线/进度 → 热点 HTTP → StopWatch 绘制
```

手机负责定位、WGS84转GCJ-02、高德底图与算路、路线匹配和进度；手表负责小智语音、配网、收图/收路线、地图窗口、标记及变色绘制。协议带会话、序号和确认，具体见 [P8协议](P8-路线与配色协议.md)。

当前链路不依赖自建服务器。队友接入网页/服务端时，需要把服务端路线交给伴随 App，再复用既有地图与路线链路；不是网页选了目的地就已自动同步到手表。现有前后端与硬件尚未共享路线、会话和业务状态。

## 尚未实现

- 手表独立 GPS、转向提示、到达判断和偏航重算。
- App 锁屏/后台持续同步；目前需保持前台，返回后重新开始。
- 网页路线与小智业务状态统一；复杂绕行、长时间断定位或重叠往返路线可能需重新规划。

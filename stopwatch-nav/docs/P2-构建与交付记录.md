## 最终实现

### StopWatch

- 版本 `2.2.6-p2-test01`，分支 `dev/p2-local-link`，基础提交仍为 `356541a94d6ea73f291388eb028a670e6c75f2f3`，本阶段源码改动见发布包 source.patch 和 source 目录。
- 新增独立的 `LocalLinkServer`，在连上 Wi-Fi 后提供 HTTP 状态与小消息确认接口，端口 8765；断网或配网时停止，重连后恢复。
- 保留小智界面，新增 IP、最近 RX 编号与累计收包计数；界面更新经主任务调度。
- 保留原 Wi-Fi 记忆、按键和“你好小智”唤醒。
- 跳过自动固件替换，保留版本请求中的云端认证、激活和语音配置获取。手动更新功能不在本次修改范围。
- 限制请求长度、字段、JSON 嵌套、接收时长、socket 数量与任务优先级；异常输入不计数。

### Android

- 同包名 `com.qixia.stopwatchnav`、同开发签名，versionCode 131，版本 `8.3.26-p2-test01`，可覆盖 P1 安装。
- 新启动页 `LocalLinkActivity`：输入 IP、检查连接、单条发送、连续十条、状态与最近四十条日志。
- `LocalLinkClient` 使用 HttpURLConnection，核对服务身份、协议版本、session、seq 和消息回显，限制响应大小和等待时间，拒绝重定向。
- 失败停止当前发送组，不自动重发未确认消息。连接状态在前台定期重试，IP 变化由用户更新。
- 离开测试页取消检测和请求；旧连接的异步结果不能覆盖新连接页面状态。此版不承诺锁屏后台工作。
- P2 页面不需要高德 Key、定位或蓝牙权限。原 MotoNav 代码与许可保留，后续复用地图功能。

## 验证结果

1. ESP-IDF 构建完成，固件图像校验有效、分区容量通过。
2. 主程序 2,961,888 字节；默认资源 2,851,767 字节。布局和资源与已验收 P1 一致。
3. Android APK 55,162,643 字节，签名验证通过，证书与 P1 一致，包名、版本和启动 Activity 均已检查。
4. 9 项 JVM 测试通过：真实本机 HTTP 通信及中文回显、错序号/会话拒绝、错误身份/协议/计数拒绝、错误/超大响应拒绝、失败后恢复、设备重启识别、取消、超时、用户 IP 校验。
5. 直接编译生产版 `local_link_server.cc` 和实际 cJSON，通过桌面 IDF 传输适配层测试：有效分段接收、15 类拒绝情况、拒绝后计数不变、服务停止/重启后保留运行计数和启动标识。
6. 7 项发布保护测试通过，包括损坏文件、异常 OTA、缺少端口拒绝。
7. 打包文件复制后逐字节核对，原 P1 回退文件 hash 匹配，源码 diff 空白检查通过。

电脑端测试不覆盖 ESP32 实际 HTTP socket 行为、Zenfone 热点路由、LVGL 实机布局、语音资源竞争或真实断线恢复，这些由用户本阶段五项测试验证。

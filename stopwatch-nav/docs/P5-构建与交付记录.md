## 实现

版本 `2.2.6-p5-test01`，分支 `dev/p5-pages-volume`，基础提交仍为 `356541a94d6ea73f291388eb028a670e6c75f2f3`。

### 页面与按键

新增 `main/boards/m5stack-stopwatch/stopwatch_pages.h`，复用 LVGL。初始化时把原界面对象移入语音页根对象，创建独立地图占位页；两个根对象长期保留，切换仅移动 X 坐标。每次动画 240ms，快速反向按键从当前偏移继续，边界重复按键不创建动画。

没有更换 LVGL active screen，原显示模块仍持有有效的字幕、状态、表情指针；原界面更新留在语音根对象内，不会在地图上覆盖显示。测试 IP/RX/VOL 信息分别更新两页。地图页明确标注尚未接入真实地图。

左右键回调通过 Application::Schedule 到主任务处理。左键 GPIO2 恢复语音，右键 GPIO1 暂停语音并进地图。启动、配网、激活或升级时拒绝进入地图，保持配网流程可见。没有新增长按功能。

### 语音互斥与异步处理

Application 新增 SetVoicePaused。进入地图先使旧语音任务失效，再暂停音频服务、清理相关待处理事件、终止并关闭音频会话，状态回到 idle，但保持 Wi-Fi。返回时按当前设备状态恢复待机唤醒，不重开旧会话。

`VoiceGate` 使用原子代次和暂停标志。已排队的 TTS/STT/表情回调带有代次，切入地图再切回也不能执行旧回调；新会话打开前不接收旧语音消息。有 session_id 的语音 JSON 还会核对当前会话，防止上一会话消息误用。无 session_id 的兼容消息仍依赖通道状态和代次，不能声称识别了服务端未提供的会话归属。

AudioService 新增 SetSuspended，停止唤醒、录音处理及音频测试，清空收发、解码和播放队列。编解码中的任务携带代次，旧结果不能重新入队；已取出的播放任务也检查代次。输出锁在切页前等待当前写入结束。恢复时先保持暂停并清理队列，再开放新代次，避免“刚恢复就接收旧队列”的时序问题。硬件 DMA 尾音和实际切页响应仍需真机确认。

### 每次启动音量 85

仅在 StopWatch 板型中，Application::Initialize 调用音频 Initialize 后、Start 前设置 85。这样先读取保存值，再覆盖为用户要求的启动值，首次声音使用新值。运行中仍允许原音量工具调节；下次启动再重设。页面显示实际 output_volume，而非固定写死的 85。

## 实现

固件 `2.2.6-p6-test01`，开发分支 `dev/p6-image-swipe`，基础提交 `356541a94d6ea73f291388eb028a670e6c75f2f3`。Android 版本 `8.3.26-p6-test01`，versionCode 132，包名 `com.qixia.stopwatchnav`，沿用 P2 开发签名，可覆盖安装。本次须同时更新固件和 APK。

触摸使用 CST820B，I2C 地址 0x15，经 M5IOE1 引脚 4 复位；每 30ms 读取 0x02 起始的接触点和坐标寄存器，0xFE 写 1 禁止自动休眠。参考现有 MotoNav SensorLib 和 Espressif 触摸驱动的寄存器布局。单指横向位移至少 65 像素、横向占优且在 1200ms 内识别，一次接触只触发一次；无效读取取消当前接触。初始化失败保留按键入口。硬件坐标及响应尚需用户验收。

触摸和按键共用调度至 Application 主任务的 RequestPage，统一执行语音暂停、图像队列活动状态及 LVGL 页面切换。继续使用两个持久页面根对象和 240ms 动画；不新增 LVGL 全局触摸设备，不让页面随手指实时拖动。

图像链路为手机 Canvas 生成测试图 → Kotlin 编码 RGB565LE → HTTP 上传 → 手表 PSRAM 缓冲校验 → 主任务安装 LVGL 图像。固定 240×240，CRC32，接收与显示分别确认。细节见 `P6-图像协议.md`。手机 A/B 图使用色带、方向箭头、四角文字及不同背景/圆点，方便检查颜色、方向与换图。

P5 的配网组件、唤醒资源和分区布局保持一致，启动音量仍为 85。本阶段没有真实地图、GPS 或高德 Key 接入。

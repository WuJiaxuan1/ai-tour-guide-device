# StopWatch 小智语音＋地图与步行路线

**当前版本：P8-test02，2026-10-30 用户确认本轮全部测试通过。** Android 为 `8.3.26-p8-test02`（versionCode 142），固件为 `2.2.6-p8-test02`。

## 已实现

- 小智云端语音、“枫叶精灵”唤醒、保留设备绑定；每次开机重新配网，默认音量85。
- 语音与地图两页，按键或左右滑动切页；地图页暂停语音。
- 手机 GPS 获取位置并转成 GCJ-02；高德生成480×480地图块，手表显示240×240源像素窗口并铺满466圆屏。位置点尽量居中，窗口移动、提前取图、对齐换块。
- 手机搜索地点或输入坐标，规划步行路线；底图和路线分别通过热点局域网 HTTP 传输，手表绘制路线与终点。
- 沿路线行走后，已走部分逐段变色；低精度、偏离、位置跳变或回走保留已确认进度。调色和换块不清零，重新规划重置。
- 手机可调地图缩放、隐藏文字、未走/已走路线、定位点、终点、描边颜色及线宽，并保存配置。常用显示为缩放14.0、隐藏地图文字。

## 验收与边界

P1～P7、P8-test02 已由用户逐阶段真机验收。P8-test02 电脑侧有52项 Android JVM 测试、C++ HTTP 协议测试、真实 LVGL 像素检查、7项发布保护检查通过。此结论不等于长期或多机型稳定性认证。

定位来自手机，手表没有独立 GPS。App 需前台运行，锁屏或切后台后返回需重新开始；退出重开需重新规划路线。当前没有转向提示、到达判断、偏航重算，也尚未接入项目服务器；网页与 Android/手表未共享路线或小智会话。

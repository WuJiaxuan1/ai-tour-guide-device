# 栖霞山智能体知识库 MVP 人工审阅清单

## 当前范围

- 默认入口：栖霞山西门售票处。
- 候选景点：12个；它们构成推荐池，不要求每条路线全部经过。
- 推荐路线前必须询问：到达时间、游览时长、体力、兴趣、是否用餐、离园时间。
- 高德负责距离、时间与步行折线；本知识包负责讲解、推荐理由、偏好和回答规则。

## 已完成

- 12张统一字段的景点知识卡。
- 西门入口及沿途卫生间、游客中心、餐饮候选。
- 情侣、闺蜜、独行、轻松、赏枫摄影、茶文化6类偏好。
- 13条智能体推荐与安全回答规则。
- 高德入口对比和扩展点距离计算。

## 当前禁止直接回答的内容

- 未核验前不得声称某个卫生间或餐厅“最近”。
- 不得把小红书情侣路线称作官方路线。
- 不得保证某天红叶已红、机位无人或固定时间免票。
- 不得把高德步行时间当成包含爬升、排队和游览停留的总时长。
- 不得虚构钟鼓楼、桃花湖和太虚亭缺失的历史细节。

## 本轮采风优先级

1. 核验西门到彩虹明镜、钟鼓楼及寺院文化区的真实入口。
2. 为明镜湖、鼓楼、千佛岩、太虚亭卫生间记录GPS坐标。
3. 实测红叶谷与太虚亭方向的坡度、台阶、耗时和退出点。
4. 核验陆羽茶庄及古镇餐饮的营业状态。
5. 为情侣/闺蜜模式拍摄可复现的双人机位示例。

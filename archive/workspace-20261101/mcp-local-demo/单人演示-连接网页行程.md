# 单人演示：让小智读取网页选择

最新启动步骤、角色提示词、验收清单与代码交接，请阅读：

[网页与小智本地验收](../ai-tour-guide-device/docs/handoffs/单人演示-网页与小智验收.md)

后端使用 npm run start:demo（普通 npm start 默认关闭演示）。构建后直接打开 http://127.0.0.1:8787/。

网页显示“已同步到本机服务”，不表示手表已连接；小智调用工具仍需运行本目录 run_cloud.py 并完成智能体角色配置。

本版同步地点/设施、顺序、出入口、停留分钟、打开的景点详情和最近三条已发送问题；不含GPS、实际路线或导航进度。

另一个浏览器不能覆盖当前演示。结束演示后清除服务器内容；固定两小时到期。刷新同一个标签页能恢复，关闭标签页前应主动结束。

本地验证：

- .venv/Scripts/python.exe -m unittest -v test_knowledge test_demo
- .venv/Scripts/python.exe local_check.py
- .venv/Scripts/python.exe demo_integration_check.py

前两项检查知识、协议和失败边界；最后一项使用隔离的真实本地HTTP和MCP客户端，验证保存、变更、输入、结束、查询与权限隔离。不会连接小智云端或修改现场演示。

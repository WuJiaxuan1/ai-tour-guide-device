## 本次效果与使用条件

手机获取真实 GPS → 转换成高德坐标 → 高德 SDK 在手机绘制周边底图 → 通过热点发给手表。底图不足时更新一张图，平时约每秒单独发送位置，手表在地图上移动蓝点。

- 地图北朝上，240×240，包含地名、道路和高德标识，不旋转地图，不规划路线。
- 沿用左滑/右键进入地图、右滑/左键返回语音。“枫叶精灵”、开机音量 85、开机重新配网保持。
- 手机和手表之间仍走手机热点局域网。手机移动数据用于加载高德地图与小智联网。本阶段不需要配置自建服务器。
- **App 必须保持前台。切到其他应用或锁屏会停止同步，返回后点“开始定位和地图同步”。** 运行时 App 请求保持屏幕亮着，但手动锁屏仍会暂停。
- 首次定位请到室外开阔处。只使用真实 GPS，不以模拟点、上次缓存位置或固定城市冒充当前位置。
- 仅显示精度不差于 50 米、年龄不超过 15 秒的位置。断开 App 后，旧蓝点会在约 15 秒、再加一次屏幕状态刷新内隐藏；完整底图可以继续保留。

## 2. 申请高德 Android Key

你还没有 Key，先完成这一节。Key 用于允许这个 App 加载高德地图，和小智智能体的 token 是两件不同的事。

1. 在电脑或手机浏览器打开 [高德开放平台](https://lbs.amap.com/)，注册或登录，按页面要求完成开发者信息/认证。
2. 进入 [控制台](https://console.amap.com/) 的应用管理，创建一个应用，名称可以叫“枫叶精灵”。按钮名称以控制台当前页面为准。
3. 在该应用下添加 Key，平台选择 **Android 平台**。本轮使用 Android 地图 SDK，不选 Web 服务或 Web 端，也不用申请导航路线权限来测试本版。
4. 填写下表信息。可在 App 点“高德 Key 设置 / 复制包名与 SHA1”直接复制，防止手工漏字符。

| 配置项 | 本次安装包的值 |
|---|---|
| 应用包名 | `com.qixia.stopwatchnav` |
| SHA1 安全码 | `74:EB:CA:6E:44:83:74:FC:C8:AB:AA:4F:B6:D8:D0:EB:67:CC:2A:FE` |
| 安装包类型 | 本地开发签名的调试 APK |

把上述 SHA1 填入“调试版安全码”。若控制台同时强制要求“发布版安全码”，本轮也可填写同一 SHA1，匹配目前实际安装包的签名；将来更换正式签名时再更新。不要填原版 MotoNav 的包名或签名，也不要把 SHA256 当作 SHA1。

5. 创建成功后复制生成的 Key，在手机 App 的 Key 设置里粘贴，点击“保存并重启 App”。保存后必须使用重启后的 App，让高德 SDK 采用新 Key。Key 不需要发给我。
6. 回到 App，输入手表 IP，点击“开始定位和地图同步”。如果弹定位权限，选择“使用期间允许”并开启“精确位置”；本版不要求始终允许或后台定位。
7. 首次启用会展示高德地图使用说明及隐私政策入口，阅读后选择是否启用。然后保持 App 在前台，到室外等待 GPS。

若刚授权权限后没有自动开始，再点一次“开始定位和地图同步”即可。

## 3. 五项真机验收

### 第 1 项：配置和基础回归

手表启动后音量显示 85，原智能体绑定保持；“枫叶精灵”可唤醒并对话，左右按键和滑动正常。

安装 P7 APK、配置 Key，开启手机定位，输入手表当前 IP。手表先进入地图页，然后点 App 的“开始定位和地图同步”。App 应显示已连接 `2.2.6-p7-test01`。

这时若暂未 GPS 定位，显示“等待真实定位”是正常的，不应把某个默认城市作为当前位置。

### 第 2 项：第一张真实地图

在室外静止等待，首次 GPS 可能需要几十秒甚至更久，取决于信号。App 应显示精度、位置年龄以及高德坐标；位置有效后加载周边地图。

手机页面下方有高德底图和手表预览，必要时向下滚动查看。手表应显示相同区域及蓝色定位点，顶部 `GPS +/-…m` 表示精度，`age …s` 表示位置年龄。

请核对附近实际道路、建筑或路口，不只确认“有一张地图”。地图北朝上，手机与手表颜色、方向和文字布局应对应。记录首张底图耗时、定位精度以及有无明显偏移。

App 的“底图已装载”表示手表已把图交给 LVGL，实际屏幕是否正确仍由你观察。超过 25 秒没取到完整底图会提示地图超时并稍后重试，不把不完整截图当作成功。

### 第 3 项：走动跟随和换底图

保持手机 App 前台，安全步行约 100～300 米，停下时观察：

- 蓝点是否随位置移动，方向是否正确；地图不应随手机转动而旋转。
- 底图范围足够时，“位置”计数增长，“底图”计数不应每秒增长。
- 靠近当前底图边缘时，新底图自动加载并完整替换，蓝点与新图对应。
- 停下后允许 GPS 有一定抖动；结合手机显示的精度判断，不要求像素级静止。

若步行范围不足以触发自动换图，可点一次“重新获取周边底图”验证手动换图，但请分别记录“自动换图是否实际测到”。不要边走边操作设备。

### 第 4 项：语音和地图切换

手表右滑回语音页，App 应提示“手表在语音页，已暂停地图和位置发送”。用“枫叶精灵”完成新对话，再左滑回地图页：应恢复当前有效位置，不能继续显示已过期的旧蓝点。

再测试一次小智播放长回答时切入地图页：语音应停止，地图不被旧语音界面覆盖；回语音后可以重新唤醒。往返约十次，观察是否花屏、卡死或重启。

### 第 5 项：失去定位或连接后不假装实时

先在 App 点“停止同步”，观察手表：约 15 秒、加一次状态刷新内应隐藏蓝点，显示 `GPS: waiting / stale`，底图仍可保留。再次开始后，应等待新的有效定位再恢复。

再验证以下至少一项，并说明测了哪项：

- 关闭手机 GPS，回 App 重新开始时应提示开启定位，不继续显示实时蓝点。
- 切到其他 App 或锁屏，再回到本 App：应处于已暂停，点击开始后恢复。本版暂停是预期行为。
- 短暂关闭热点后重开：手表在本次运行自动重连。App 保持前台时会重试；操作系统设置导致 App 进入后台时，回来再点开始。IP 改变则修改 IP 后重新开始。

恢复后应能再次显示地图和定位。重启手表则仍需重新配网，启动音量 85，地图 RAM 缓存清空。

## 4. 常见现象和反馈

| 现象 | 优先检查 |
|---|---|
| App 提示需要 P7 固件 | 确认手表已刷本包，不能仅更新 APK |
| GPS 一直等待或精度很差 | 手机定位开关、精确位置权限、室外开阔环境；本版没有网络定位兜底 |
| GPS 有效但地图灰白/超时 | Android 平台 Key、包名、SHA1、保存后是否重启 App、手机移动数据是否能联网 |
| 手机地图有了，手表没有 | 手表是否在地图页、当前 IP 是否正确、App 是否已暂停 |
| 定位点隐藏，旧地图还在 | 可能是定位过期/精度较差/已停止；查看手机定位状态与手表 GPS 提示 |
| `GPS: waiting for new map` | 人已离开当前底图范围；等待新底图，检查手机地图错误提示 |

```text
P7 第 1～5 项：通过 / 未通过 / 未测
Key 是否已创建并保存重启（不用附 Key）：
GPS 精度 / 年龄 / 室内或室外：
手机地图是否真实对应附近、手表是否一致：
步行大约距离，自动换底图是否实际发生：
App 底图和位置计数 / 报错原文：
语音页往返结果：
停止或断开后蓝点是否隐藏、恢复结果：
```

地图显示失败时，先发提示文字和界面照片即可，遮住 Key。我们按实际反馈排查 SDK 鉴权、GPS、热点或手表绘制，不需要先学完整 Android 开发。

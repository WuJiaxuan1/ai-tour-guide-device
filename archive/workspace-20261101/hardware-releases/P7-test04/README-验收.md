# P7-test04：方案一——扩大地图范围、提前刷新和平滑换图

2026-10-28。基于已通过的 P7-test03。本版把地图缩放级别调为 15.5，使手表中央裁切区域的范围接近手机上方预览；位置进入地图中央约 50% 以外时提前取下一张图，并加入 360 毫秒淡入换图。两端已构建、测试和打包；尚未进行本版真机复测。

## 改动

- 修复发图成功后绘制手机定位点时，向不可修改 Bitmap 创建 Canvas 的代码错误。改为在独立像素数组中画蓝点，再生成预览图片；不再手动回收仍可能被 ImageView/渲染线程或 SDK 持有的图片。
- 地图显示确认后立即发送最新有效位置，手机预览和手表均显示蓝点。首次无有效 GPS 时明确等待，不以假位置代替。
- 手表真实地图铺满 466×466 圆屏，移除地图页上的大标题、IP/RX/VOL 调试区及底部切页文字，仅保留小型 N/GPS 状态；原按键和左右滑动仍可用。地图替换时短暂淡入，旧图在新图确认前保留。
- 定位点扩大为 24 像素蓝点，带白边；与底图采用同一比例转换坐标。有效位置随移动更新，旧位置过期时隐藏。
- 手机 SDK 使用 480×480 地图视图，缩放 15.5，发送中央 240×240 区域，避开底部高德标识，并按裁切边界计算经纬度。没有用纯色块涂掉地名或道路。手机原始 SDK 视图仍保留其默认标识；“手表地图预览”展示实际导出的中心区域。
- App 增加“查看上次闪退记录”。若仍退出，可重新打开后查看记录并反馈。

本版传输分辨率仍为 240×240，由手表放大铺满圆屏，不是原生 466×466 高精度底图。协议和内存预算不变。缩放级别降低一档会扩大范围，但道路文字相应变小；实际比例尺、切换动画和圆屏边缘显示均需此次真机检查。

## 安装：这次手机和手表都更新

### 手机

将本目录 `maple-map-P7-test04.apk` 传到手机覆盖安装，不卸载、不清数据。包名、签名与 SHA1 没变，P7-test02 已保存的 Key 应保留。首页应显示 P7-test04。

### 手表

连接 StopWatch 数据线，确认实际 COM 端口，关闭占用串口的软件。PowerShell 执行，替换 `COM实际端口`：

```powershell
Set-Location 'D:\Study\yiqifen\stopwatch-nav\releases\P7-test04'
& 'D:\Study\yiqifen\stopwatch-custom\.venv-flash\Scripts\python.exe' .\flash_p7.py --check-files
& 'D:\Study\yiqifen\stopwatch-custom\.venv-flash\Scripts\python.exe' .\flash_p7.py --flash --port COM实际端口
```

脚本只写核对后的当前应用槽和配套资源，不全片擦除、不写 NVS/分区表/bootloader/OTA 选择。手表版本应为 `2.2.6-p7-test04`。

沿用既有配网流程：手机连手表热点 → 输入手机热点名称/密码 → 保存 → 开始连接 → 手机开自身热点，中间不重启。每次开机音量仍为 85，唤醒词“枫叶精灵”，云端绑定应保持。

## 本轮五项验收

1. **首图后不闪退。** 手机 App 前台、GPS 有效，手表进入地图页，开始同步。地图装载后观察至少两分钟，手机正常显示预览，位置计数持续增加。
2. **范围比例。** 对照手机上方地图预览和手表画面，手表应显示接近相同的地理范围；道路文字变小属于缩放级别降低后的预期现象。
3. **提前换图。** 步行使蓝点从地图中心向边缘移动，观察 App 状态。应在明显贴近边缘前开始获取下一张地图，旧地图仍显示；新图完成后应有短暂平滑淡入，不应出现空白页。
4. **当前位置。** 手机有不差于 50m、年龄不超过 15 秒的真实 GPS 时，手机预览和手表均应有蓝点。步行 100～300m 检查蓝点、道路和地图范围是否一致。
5. **切页和停止恢复。** 回语音页唤醒并对话，返回地图恢复定位；停止手机同步后旧点按原规则隐藏，完整地图可以保留。重新开始可恢复。App 仍要求前台运行，锁屏/离开页面会暂停。

## 如果仍闪退

重新打开 App，点击下方“查看上次闪退记录”，发出其中异常类型和堆栈文字，或拍照。记录可能是修复前留下的旧记录，请带上记录时间。可先清除旧记录，再重现一次以便区分。

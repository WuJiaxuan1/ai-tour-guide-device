# P8-avatar-test02：倾斜跟随＋单击／双击互动

基于用户已验收的 P8-avatar-test01。新固件版本：`2.2.6-p8-avatar02`。

本版需要更新手表固件，手机继续使用 P8-test02 App。电脑构建和测试结果见包内日志及 `build-report.json`；**真机验收待完成**。这次没有自动烧录设备。

## 新增效果

- **倾斜跟随**：慢慢向左右、前后倾斜设备，眼睛与头部姿态随之变化。语音待机时动作较明显；聆听、思考、回答时幅度减小，原对话表情继续播放。
- **单击开心**：语音待机时轻点一下屏幕，松手约0.3秒后露出笑眼，然后回待机。这段等待用于确认你是否还会点第二下。
- **双击惊讶**：在相近位置快速点两下，显示惊讶；不先播放开心，再播放惊讶。
- 进入对话、地图页或配网页时，取消尚未触发的点击。左右滑动继续切页，长按和拖动不触发上述表情。

本批未开启触摸拖动跟随、长按生气、摇晃眩晕或震动。表情仍为黑底全屏，没有新增操作文字。

## 先这样试倾斜

1. 配网完成，看到待机眼睛后，按平时使用的姿态拿好设备，稳定保持约1秒。
2. 慢慢向左、向右、向前、向后倾斜约10～25度，看眼神是否响应。
3. 恢复刚才的握持姿态，眼神应逐渐回正，仍有原本轻微的待机观察动作。

设备使用 BMI270 的加速度和陀螺仪，以进入语音页时的稳定姿态作为中间位置。连续20个稳定样本完成校准，正常约0.8秒；一直移动时会等待。每次从地图回语音页会重新校准。想重新调整中间位置，可切到地图再切回来，稳定拿住约1秒。

请用“倾斜”测试，平放在桌面上仅水平转圈并不是本功能主要识别的动作。它不提供 GPS 或指南针方向。方向与幅度仍需这轮真机确认。

## 七项验收

| 项目 | 操作 | 通过标准 |
|---|---|---|
| 1. 开机 | 重启、配网，进入语音页 | 配网和绑定正常，最终全屏眼睛，默认音量85 |
| 2. 倾斜 | 稳定拿住1秒，分别左右、前后缓慢倾斜，再回正 | 视线有对应变化，能持续保持倾斜后的偏移，回正顺滑；不突然抖动或卡死 |
| 3. 单击 | 待机时轻点一下并松开，等待 | 约0.3秒后开心，然后回待机；不切页，不启动对话 |
| 4. 双击 | 待机时在相近位置快速点两下 | 惊讶后回待机，不先闪出开心；反复尝试几次结果稳定 |
| 5. 手势区分 | 慢拖、长按，再左右滑动及按键切页 | 慢拖和长按不变开心/惊讶；原切页方式正常，切回来不会补播刚才的点击 |
| 6. 对话优先 | 点一下后立即唤醒；对话中再点按、轻微倾斜 | 待触发点击被取消，聆听和回答正常；对话中点按不触发开心/惊讶；倾斜幅度较小，音频没有明显新增卡顿 |
| 7. 导航与持续使用 | 原 App 同步地图和路线，走一段；多次切页并使用约20分钟 | 地图、定位点、路线及已走变色正常；地图页没有表情覆盖；返回语音能重新校准、唤醒；无重启或花屏 |

反馈“第几项＋具体表现”。倾斜问题请说明：静止时是否正常、左右与前后哪个方向不对、完全不动还是幅度太小。能录一小段手持倾斜的视频会更方便判断。

## 没有倾斜反应时

先确认手机连接状态中的手表版本为 `2.2.6-p8-avatar02`，并在语音待机页稳定拿住1秒。再试切到地图、切回语音页重新校准。若点按有反应但倾斜没有，不需要反复重刷，把现象告诉我。

供排错使用：串口日志正常应先出现 `BMI270 ready`，稳定拿住后出现 `IMU neutral calibrated; tilt follow enabled`。如果出现初始化失败或读取不可用，固件会保留语音、导航和点按能力；丢失传感器数据约250毫秒后，视线目标回到中间，恢复读取后重新校准。无需为普通验收先配置串口监视器。

## 开发交接

- `avatar_input.h`：单击/双击与拖动取消、静止校准、轴映射、滤波和陀螺仪前馈；阈值集中在此，便于后续按真机效果调节。
- `stopwatch_imu.*`：使用工程已有的 Espressif BMI270 驱动，100Hz输出、约40ms采样一次；复用原 I²C 总线，不新建同引脚的第二条总线。
- `avatar_display.*`：将传感器和点击接入表情，处理页面、对话状态和数据过期。
- `m5stack_stopwatch.cc`：连接原触摸采样任务与独立 IMU 任务。左右滑动识别仍使用原 `SwipeTracker`。
- `tests/p5host/avatar_input_test.cc`、`avatar_test.cc`：覆盖点按/滑动/长按/错误/切页取消、校准与方向映射、越界保护、真实 LVGL 表情绘制及页面隔离。

电脑测试验证算法和显示集成，不能替代 BMI270 真机初始化、实际手感、共享总线与音频并行测试。表情代码与移植思路沿用 AGPL-3.0-or-later 上游，来源说明随源码；传感器依赖与 Bosch 配置数据许可见包内 `third-party/`。原小智音频、网络、导航协议与地图绘制逻辑未修改。

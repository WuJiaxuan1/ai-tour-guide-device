# P8-avatar-test07：眩晕结束自动恢复识别＋点按互换

版本：`2.2.6-p8-avatar07`。本版解决 test06“摇晃后必须切地图再回来才能再摇”的反馈，同时按要求交换单击、双击表情。电脑测试与构建结果见包内日志，**真机验收待完成**；未自动烧录，手机不用更新。

## 本次效果

- **眩晕播完自动开放下一轮摇晃**：不必切页，也不再要求拿稳0.65秒、等待3秒才能解锁。
- 播放眩晕时不累计新手势，也不会不停重启动画。回到普通待机眼睛后，重新连续左右摇一组即可再次触发。如果一直摇，会在每段眩晕完整播完后，再识别新的一组摇晃。
- **单击 → 惊讶，双击 → 开心**。单击仍会等约0.3秒，用来判断有没有第二次点击。
- 原固定竖直倾斜、配网、唤醒词、音量85、绑定、导航和切页沿用。

## 原因与验证

test06要求“冷却时间已过，而且连续拿稳650ms”才能重新识别。手中持续有轻微动作时，拿稳条件可能一直不满足；切页会重置识别器，所以看起来只有切页才能恢复。

电脑上用“首次摇晃→持续小幅手部动作→再次摇晃”复现：旧版总计触发1次，新版触发2次。真实桌面LVGL测试还覆盖不切页连续五轮、持续摇晃时先播完再重新识别、缺读恢复，以及对话/云端/地图取消。此处是软件测试证据，尚无本设备时序日志确认唯一原因。

## 六项验收

| 项目 | 操作 | 通过标准 |
|---|---|---|
| 1. 反复摇晃 | 待机时左右摇，等眩晕播完，再摇；不切页连续试5次 | 每次都能触发并恢复，不需切页或特别拿稳解锁 |
| 2. 持续摇晃 | 连续摇约8秒 | 每次眩晕能完整播完，之后识别新一组；不会一帧一帧重启或永久卡在眩晕 |
| 3. 单击/双击 | 待机单击，等表情结束；再快速双击 | 单击惊讶、双击开心；双击前不先闪出惊讶 |
| 4. 对话优先 | 眩晕时唤醒；对话中点按或摇动；结束后回待机再摇 | 语音正常，互动不抢占对话；回待机后可重新触发 |
| 5. 切页与误触 | 摇一半或眩晕中切地图，再回来；普通慢倾斜、拿起放下 | 地图不受影响，回来不补播；普通动作不容易误触，倾斜仍顺畅 |
| 6. 导航回归 | 按键/滑动切页、手机同步定位和路线、已走变色，使用约10分钟 | 原功能正常，无明显音频卡顿、重启或花屏 |

若仍出现一次后不再触发，先观察是否已经回到普通待机眼睛，再采集20秒日志：


采集期间摇两轮，不切页。日志会显示 `ver=2.2.6-p8-avatar07`、`Repeated horizontal shake -> DIZZY`，以及新增的 `DIZZY completed; fresh shake recognition rearmed`。播放中 `enabled=0`、播完后变为1是预期；脚本只收集表情相关诊断，不烧录。

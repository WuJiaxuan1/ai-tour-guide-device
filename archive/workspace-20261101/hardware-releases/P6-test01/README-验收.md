按已通过的流程配网：手机连手表热点 → 填手机热点名称和密码 → 保存 → 点“开始连接” → 手机开启自身热点。保存和连接之间不要重启手表。

## 2. 五项真机验收

### 第 1 项：原有功能保持

开机配网后进入语音页，显示 `VOL 85`；原智能体绑定保持。说“枫叶精灵”，完成一轮对话。新版 App 能检查连接，并连续发送十条测试消息。

### 第 2 项：屏幕滑动和按键

在屏幕中央从右往左滑，进入地图页；从左往右滑，回语音页。重复约二十次，包含几次较快的交替滑动。页面不应卡在半屏、花屏或重启。

再试轻点、上下滑动，应保持当前页；语音页向右滑、地图页向左滑，都不应出现第三页。右键进地图、左键回语音仍可用。地图页说唤醒词不启动对话；回语音页等待待机后能重新唤醒。

若滑动无反应但按键正常，请报告这一差别，继续用按键完成后面的图片测试。触摸芯片和实际坐标方向还需要这次真机确认。

### 第 3 项：第一张图

先在手表进入地图页，保持 App 在前台。等待连接状态更新后，点击“发送测试图 A”。若按钮暂时不可点，等几秒或重新检查连接，并确认手表确实在地图页。

比较手机预览与手表画面：顶部色块从左到右为红、绿、蓝；N 箭头向上；TL/TR/BL/BR 四角文字位置一致；底部 TEST A 与图像编号一致。图片居中显示，不要求铺满整个圆屏。

App 应先报告完整接收并校验成功，随后报告显示确认。这里的显示确认是手表程序已把图交给 LVGL，**实际屏幕是否正确仍由你观察**。记录第一次传图耗时，以及有无明显等待。

### 第 4 项：连续换图和恢复

A/B 交替发送约十次，每次等上一张完成。A/B 背景、箭头和圆点位置不同，应确实更新，不能一直显示旧图或出现半张新图。

再尝试发送期间点“停止发送 / 断开检测”、切回语音页或关闭热点，任选一种。预期可能保留完整旧图，也可能因传输已经结束而显示完整新图；不应出现破图或死机。单张图可能传得很快，若来不及中断，请记录“未赶上传输中断”，不要算作已验证。

恢复热点后，设备应在本次运行自动重连。必要时更新 IP 并检查连接，回到地图页再次发图，应恢复成功。图像不会因网络恢复而自动重发。

### 第 5 项：语音恢复和重新开机

语音页让小智讲长故事，播放时向左滑，声音应迅速停止。地图页发送图片，再向右滑回语音页，应能重新用“枫叶精灵”唤醒、完成新对话，不能续播旧故事。

不重启时，再回地图页可看到上一张完整图。重启后图片缓存清空，重新配网，音量恢复 85；地图页等待手机发图，重新连接 App 后可以再次发送。

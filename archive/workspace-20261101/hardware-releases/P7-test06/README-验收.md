# P7-test06：比较地图文字显示

手机安装 [maple-map-P7-test06.apk](maple-map-P7-test06.apk)。手表继续使用 P7-test04 固件，无需重刷。直接覆盖安装，不要卸载；包名和签名不变，会保留高德 Key、手表 IP 和地图缩放设置。当前缩放 **14.0** 会保留。

## 怎么比较

1. 手机开热点，手表联网并切到地图页。打开 App，点“开始定位和地图同步”。
2. 在“地图文字”下面点“标准”，等待“手表已应用”，看一下手表上的地名和标志。
3. 点“隐藏地图文字”，等再次显示“手表已应用”，比较道路和地名。道路底图保留，不会清空整张地图。设置会记住，之后可随时切回“标准”。

高德 Android 地图组件提供的是显示/隐藏地图文字的开关，没有可验证的独立字号、POI 图标缩放档位。隐藏模式会关闭地图文字标注；若仍看到独立的图标符号，那一类符号无法通过这个开关单独去掉。地图署名和版权标识会保留。

- 你想长期用“标准”还是“隐藏地图文字”？

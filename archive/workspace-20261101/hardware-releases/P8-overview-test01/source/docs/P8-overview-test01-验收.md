# P8-overview-test01：全程路线总览

固件 `2.2.6-p8-overview01`，App `8.3.26-p8-overview01`（143）。按本次要求基于 avatar11 表情/语音代码和 P8-test02 手机 App 开发。本包待真机验收，不代表已经安装到手表。

## 实际效果

规划步行路线后，地图自动缩放，让整条路线、起点和终点放进圆屏，并给边缘留空。地图保持北朝上、位置固定，当前位置点随手机 GPS 移动，已经走过的路线继续变色。长路线看全程，因此附近道路会比巡航模式小。

总览不显示地名、地图标注、北向字母、GPS 文字和切页提示。绿色圆点为起点，终点/定位点/未走路线/已走路线/描边沿用手机已保存的颜色；起点绿色暂不单独调色。当前位置与起点重合时，定位点在上层。

手机可切“显示全程路线”与“跟随当前位置”。默认全程模式；尚未规划路线或取消路线时，显示原周边巡航地图。巡航沿用原设置（默认缩放14.0、隐藏标注）；总览使用自动范围，不受14.0限制。地图资源仍来自高德，手机仍需保持 App 前台、开启定位并与手表处于同一热点局域网。

## 安装两端

1. 将本目录 `maple-map-P8-overview-test01.apk` 发到手机，直接覆盖安装原开发 App。包名和签名相同，保留高德 Key、IP、配色与巡航缩放设置，无需先卸载。
2. USB连接 StopWatch，关闭 M5Burner/串口监视器等占用串口的软件，按实际端口修改下面的 `COM实际端口`：

```powershell
Set-Location 'D:\Study\yiqifen\stopwatch-nav\releases\P8-overview-test01'
& 'D:\Study\yiqifen\stopwatch-custom\.tools\espressif\python_env\idf5.5_py3.12_env\Scripts\python.exe' .\flash_p8.py --check-files
& 'D:\Study\yiqifen\stopwatch-custom\.tools\espressif\python_env\idf5.5_py3.12_env\Scripts\python.exe' .\flash_p8.py --flash --port COM实际端口
```

脚本检查分区、OTA状态和文件校验值，更新当前应用及配套资源，不写NVS、引导或分区表。不要用整片擦除。开机配网、云端绑定、音量85与“枫叶精灵”沿用。

3. 手表配网并切到地图页。手机点“开始定位和地图同步”，取得有效定位，再搜索一个目的地并规划步行路线。第一次建议选500米～2公里的目的地，等手机提示地图/路线已接收。

## 六项验收

1. **完整无字总览**：整条路线、起终点都在圆屏内，周围留有余量；没有地名、GPS/N或其他文字。手机下方圆形预览与手表范围一致。
2. **走动更新**：在室外沿路线走一段，底图不跟着滑动，定位点移动，已走路线变成设定颜色。路线很长时移动幅度会较小，可用短路线检查。
3. **改色与换路线**：调整未走、已走、终点和位置点颜色，应更新且保留已走进度。重新选较远/另一方向目的地，整幅地图重新适配新路线，进度重新开始，不能把新路线叠到旧范围上。
4. **模式切换**：切“跟随当前位置”，恢复位置居中、窗口移动及原缩放滑条；再切“显示全程路线”，整条路线完整显示。取消路线后恢复周边地图。
5. **切页及定位中断**：切到语音再返回，恢复地图与路线。暂时关闭手机定位或停止同步后，旧定位点隐藏，完整路线与已走颜色保留；恢复定位/同步后位置点重新出现。
6. **avatar11回归**：每次开机配网、音量85、左键开始语音、对话和切页后唤醒、单击惊讶/双击开心、倾斜跟随、摇晃眩晕和短震均保持 avatar11 的行为。

反馈“哪项未通过＋手机状态提示＋手表照片”即可。本次没有更换 avatar11 的摇晃算法。

## 实现与测试边界

手机按墨卡托坐标计算路线外接范围，再用高德实际投影调整缩放，确保路线在圆屏内；自动缩放限制3～18，超大或无效范围给出错误。底图与路线继续分开传输，改色和走动无需重发地图。

新增 QMAP v4 全图显示，480×480映射到466×466；旧v3仍是480地图块中的240窗口。地图携带路线几何CRC，手表只叠加匹配的路线。网络切换、新路线及过期截图仍有代次校验。协议见 `docs/P8-全程总览协议.md` 的源文件快照。

离线检查包含 Android JVM 测试、真实C++ HTTP接收、实际桌面LVGL绘图、avatar11交互/震动、语音切页/唤醒恢复、资源及发布保护。桌面绘图截图使用合成色块底图，用于检查比例和图层，不是真机高德地图照片。高德实际取图/缩放、手机兼容、圆屏观感和户外定位仍需上述真机验收。

当前不增加转向播报、偏航重算、服务器链路或锁屏后台同步。

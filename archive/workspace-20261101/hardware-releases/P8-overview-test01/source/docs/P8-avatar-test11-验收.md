# P8-avatar-test11：摇晃识别调整＋触发短震

版本：`2.2.6-p8-avatar11`。基于用户已确认唤醒恢复测试通过的test10。手机App无需更新。本版尚待真机确认，未自动烧录。

## 现在怎样使用

在小智待机表情页，连续左右摇晃约两三个来回。允许稍微斜着晃，不要求每一次都严格水平。成功识别后：**开始眩晕表情，同时短震一下**。眩晕播放完后自动恢复，可以再次摇晃，不用切地图。

只有实际显示这次摇晃表情时才请求震动，不是每晃一下都震。短震沿用已有强度160/255、45ms；马达工作及结束后180ms余振期间暂停处理倾斜/摇晃输入，随后恢复，防止马达引起连锁触发。

摇晃只在待机空闲时识别；点按表情、眩晕动画播放中、聆听/思考/回答和地图页不积累下一次摇晃。请等上一段表情结束再试。语音及切页优先，可取消待执行或正在执行的短震。

## 本次调整

- 侧向动态加速度阈值：0.32g → 0.28g，让力度适中的摇晃更容易被接受。
- 方向比例要求：1.15 → 0.85，容忍手握设备时略带前后或上下分量的斜向动作。
- 相反方向之间最短间隔：100ms → 70ms，减少较快摇晃受采样时刻影响而漏计。
- 仍要求四次交替的有效侧向运动；保留超时、长时间缺失采样、切页和语音状态清理，以及眩晕播完重新识别的机制。
- 成功触发本地眩晕时新增一次短震，复用已有异步马达驱动，不在绘图线程中等待马达。

电脑回放覆盖1200组不同力度、速度、起始相位、斜向分量、采样抖动和丢样组合：旧版784组完整触发一次，新版1200组完整触发一次。**这是合成信号测试，不是真机识别成功率，也不能证明覆盖你的实际摇晃动作。** 原有单次碰撞、缓慢倾斜、拿起设备、弱晃动和其他方向的拒绝测试继续通过；实际走动误触仍需你检查。

## 六项验收

1. **相同晃法连续10次**：待机时用平常的力度左右摇晃，每次等眩晕结束再做下一次。记录10次里成功几次；再稍微斜着握住试几次，避免只用很大力度测试。
2. **触发短震**：每次眩晕开始应短震一下。没有触发表情时不震；眩晕过程中继续晃，不连续嗡嗡震，也不无限延长动画。
3. **自动恢复**：不切页反复做5轮，确认动画结束后能再触发；震动结束后倾斜跟随恢复正常。
4. **误触检查**：正常走动、拿起/放下、慢慢倾斜和单次轻碰，不应轻易进入眩晕或震动。
5. **语音与切页优先**：待机摇晃时按左键开始语音或切地图，语音/导航应正常；对话及地图中摇晃不触发眩晕短震。
6. **上版回归**：对话后和切地图返回后仍能说“枫叶精灵”唤醒；单击惊讶/双击开心及各自短震、左右滑动、地图路线与已走变色继续正常。

重点反馈第1项的“成功次数/10”，以及第4项是否更容易误触。

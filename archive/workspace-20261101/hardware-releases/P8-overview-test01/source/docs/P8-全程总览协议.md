# 全程路线总览增量协议

在既有 `/api/v1/status` 返回 `overview_protocol:1`。旧App可忽略；新App在全程模式要求此能力，巡航仍兼容旧固件。

`POST /api/v1/image` 延续application/octet-stream、QMAP头、会话/帧号、图像确认与RGB565LE。v4的version和type（偏移4、5）均为4，图宽高480，头96字节，像素460800字节。v4标记overview=true、chunk=false；显示完整底图，不使用240裁剪窗口。

地理范围仍在48/56/64/72的float64LE，依次north/west/south/east。80为GCJ-02编号1；84..87为uint32LE路线几何CRC32。其余保留字节为0。CRC内容为QRTE字节64至末尾，即目的地lat/lng、随后全部路线点lat/lng，不含颜色、revision或reset标志。v1/v2/v3不允许此保留字段非零。

v4允许纬经跨度小于20度，v2/v3仍小于0.1度；坐标仍受有限数、纬度(-85,85)、经度[-180,180]和大小关系校验。像素CRC/上传长度/会话及帧确认机制不变；几何CRC用于配对图层，不作为身份鉴权。

QRTE协议本身未改变。固件解析QRTE时计算相同几何CRC，只有会话和几何均匹配v4底图时才绘制路线与起终点。更换路线途中宁可暂时隐藏不匹配的路线，不能将新路线误投影到旧总览。颜色变化不重新截图；新规划清零进度，颜色变化保留进度。

手机初始相机由路线全部点与目的地的墨卡托包围盒求中心，再按最远点距离估算缩放。使用高德实际裁剪边界复核，每个路线点必须在480图中心半径199像素内（目标198，给标记/描边留空），不足或超出时调整相机再取图。总览关闭地图文字/建筑，北朝上、俯视。地图背景仍沿用高德，不复刻参考图的地形样式。

手表v4不移动窗口。路线坐标、GPS及标记均以完整480地理范围换算到466圆屏；总览隐藏地图页全部文字。GPS失效时隐藏点，保留路线和进度。超出图像边界的点隐藏，超出圆屏可视区的点由物理圆屏裁掉；不为偏离路线的定位重新适配地图。

本阶段修改文件：Android的RouteOverview、PhoneMapRenderer、SurroundingMapActivity、MapFrameEncoder、MapPreviewPixels、LocalLinkClient和SurroundingMap；固件的map_frame、route_frame、stopwatch_pages、local_link_server。表情、按键、马达、音频、唤醒与配网按avatar11快照校验。

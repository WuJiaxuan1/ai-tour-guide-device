# P7-test05：手机直接调节手表地图范围

只更新手机 APK：`maple-map-P7-test05.apk`。手表继续使用 P7-test04 固件，不用重刷。

直接覆盖安装，不要卸载旧 App。已核对包名和签名与 P7-test04 相同，会保留高德 Key、IP 和授权设置。

## 怎么调

1. 手机开启热点，让手表联网并切到地图页。打开 App，确认 IP，点击“开始定位和地图同步”，等待有效 GPS。
2. 找到“地图范围”滑条。向左调是看更远，向右调是看更近；也可点“－ 看更远”或“＋ 看更近”，每次变化 0.5 级。
3. 原范围为 **15.5**。先试 **14.5**，等待显示“手表已应用”，再试 **13.5**。可选 13.0～18.0。每降低 1 级，覆盖宽度大约翻倍、面积约四倍，但小路和文字可能随高德地图层级变化而减少。
4. 滑条松手后自动获取并发送新图，无需重启。地图加载或发送可能需要几秒；期间保留旧图。以“手表已应用”和手表实际显示为准。无有效 GPS、网络未连接或手表在语音页时会等待。
5. 选择会保存在手机上，下次打开沿用；“恢复原范围（15.5）”可恢复本次更新前的范围。

手机上方是完整 SDK 地图，手表仍取其中心区域；下方“手表地图预览”是已确认装载的整张手表底图及定位点。手表圆屏会裁掉方图角落，且保留现有居中平移行为，因此请最终以手表为准。此次改变的是地图地理范围，地图仍铺满屏幕。

## 请检查这四项

1. 15.5 → 14.5 → 13.5 时，手表可见范围逐步扩大，地图仍铺满屏幕，蓝点位置正常；告诉我最合适的数值。
2. 连续快速选择几次，最后停在某一级；加载完成后“手表已应用”，最终图应对应最后选择。已开始发送的旧图可能先完成，随后会换成最新选择。
3. 退出再打开 App，级别被保留；点开始后按该级别同步。高德 Key 不需重填。
4. 切到语音页能对话，再切回地图页继续同步；刷新时不闪退。

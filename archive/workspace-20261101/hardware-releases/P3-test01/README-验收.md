# P3-test01：每次开机重新配网

日期：2026-10-27。P3 的以下五项已由用户确认全部通过，保留本说明作为配网操作参考和 P4 回退步骤依据。P3 只更新手表，手机继续使用 P2 App。

## 本次改变

每次开机，手表清空上次保存的 Wi-Fi 列表，进入配网。同一次开机内，断网仍可自动重连。实现保留设备身份与云端绑定配置，实际绑定是否保持由下面的真机步骤确认。

配网现在支持：先填写手机热点名称和密码，保存后点击“开始连接”，然后在同一部手机上开启热点。手表会留出约 120 秒等待连接，过程中不要重启手表。

固件版本为 `2.2.6-p3-test01`。唤醒词仍是“你好小智”，当前没有地图页或定位；“枫叶精灵”唤醒词是下一阶段 P4。

## 1. 更新手表

使用数据线连接 StopWatch，查看真实串口号，并关闭占用串口的软件。在 PowerShell 中执行以下命令；将 `COM实际端口` 替换成你看到的端口号。

```powershell
Set-Location 'D:\Study\yiqifen\stopwatch-nav\releases\P3-test01'
& 'D:\Study\yiqifen\stopwatch-custom\.venv-flash\Scripts\python.exe' .\flash_p3.py --check-files
& 'D:\Study\yiqifen\stopwatch-custom\.venv-flash\Scripts\python.exe' .\flash_p3.py --flash --port COM实际端口
```

脚本检查文件、设备分区表和 OTA 状态，写入当前应用槽与配套资源，并校验写入结果。遇到 STOP 请保留输出反馈，不绕过检查。不要使用全片擦除。

烧录脚本不写 bootloader、分区表、OTA 选择或 NVS。但 P3 程序启动时会主动清理 NVS 中的 Wi-Fi 名称和密码列表，这是本阶段的预期行为；不清理设备身份和绑定配置。

本包附带已经通过验收的 P2 回退固件。手机不需要重新安装 APK；如果尚未安装 P2 App，使用相邻 `P2-test01` 目录中的 `maple-map-P2-test01.apk`。

## 2. 用同一部 Zenfone 完成配网

这里有两个不同的热点：**手表开的配网热点**，只用于填信息；**手机开的上网热点**，供手表连接小智和手机 App。

1. 先在手机热点设置中记下自己的热点名称和密码。使用已经在 P2 验证可用的配置，频段选择 2.4 GHz，并保证手机能上网。
2. 开机后，手表应进入配网。手机暂时关闭自身热点，在 Wi-Fi 设置中连接手表显示的 `Xiaozhi-…` 网络。手机提示“无法访问互联网”时，选择保持连接。
3. 打开配网页。如果系统没有自动弹出，在浏览器地址栏输入 `http://192.168.4.1`。这个地址只在手机连接手表配网热点时有效。
4. 手动填写第 1 步记下的**手机热点名称和密码**。不要填写 `Xiaozhi-…`，扫描列表里没有手机热点也可以手动填。
5. 点击“保存网络信息”。完成页应写“网络信息已保存”，此时还没有联网。
6. 点击“开始连接”。等待页面提示切换；如果配网热点已经消失，直接继续下一步。
7. 到手机设置中离开手表的 Wi-Fi，开启自己的手机热点。**保持手表开机，不要按重启。** 手机是热点提供方，不需要连接自己开的热点。
8. 等手表连接并回到小智界面。正常情况下无需用完 120 秒；若超时仍未连接，它会返回配网模式，可重新核对并填写信息。
9. 打开 P2 App，输入手表显示的**新 IP**，点击“检查连接”。应显示通信可用，固件版本为 `2.2.6-p3-test01`。这里用的是手表加入手机热点后获得的 IP，不是配网页的 `192.168.4.1`。

如果 Zenfone 支持 Wi-Fi 与热点同时开启，也可以使用；第一轮建议按上述先后切换流程验证，避免依赖这个额外能力。

## 3. 请验收五项

| 项目 | 怎么操作 | 通过时应看到什么 |
|---|---|---|
| 1. 开机重新配网 | 原来用过的手机热点已开启时，重启手表 | 仍进入配网，不自动连接旧热点 |
| 2. 同一手机切换 | 按上面第 2 节，手动填暂未开启的手机热点，保存、开始连接，再开启手机热点 | 无需重启即可联网；仍绑定原智能体，不要求重新激活 |
| 3. 原功能回归 | 用“你好小智”完成至少一轮对话，再在 P2 App 检查连接、发送十条消息 | 录音播放正常，十条均有确认，App 识别 P3 版本 |
| 4. 本次运行重连 | 不重启手表，只关闭并重新开启手机热点 | 手表能自动重连；返回 App 后点击检查连接，IP 变了先更新，再发一条成功 |
| 5. 重复开机 | 再次重启，重复配网、联网和对话；完整开机配网流程共做三次 | 每次都重新配网，保存后不陷入重启循环，绑定与语音仍正常 |

第 4 项中的 App 仍有 P2 的限制：离开测试页会暂停检测，回到 App 后需要点击“检查连接”。

可选额外检查：填错密码或暂不开热点，观察约两分钟后是否返回配网；这不是必需的五项之一。

## 4. 出问题时反馈

```text
P3 第几项失败：
手表显示或播报：
配网页停在哪一步：
手机现在连接手表 Wi-Fi，还是正在开自身热点：
点击开始连接后等了多久：
App 提示 / 手表当前 IP：
是否意外重启过手表：
是否要求重新激活 / 原智能体是否变化：
```

不要发送热点密码或接入 token。配网页说未收到切换确认时，先看手表配网热点是否消失：已消失就开启手机热点观察手表；仍在则保持连接后重试。不要用重启代替“开始连接”，否则刚填的 Wi-Fi 信息会再次清空。

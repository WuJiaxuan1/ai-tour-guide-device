# P8-avatar-test05：连续摇晃后眩晕

版本：`2.2.6-p8-avatar05`，基于2026-10-31用户已验收的 **P8-avatar-test04**。本版电脑构建和测试结果见包内日志，**真机触发手感、误触情况待验收**。未自动烧录；手机 App 不用更新。

## 新增效果

在语音待机、普通眼睛状态下，竖直拿好设备，沿屏幕左右方向连续来回摇动约1秒（约2～3个来回）。识别到连续反向摆动后，显示一段眩晕表情，约1～2秒后自动回到待机。

- 普通慢倾斜、单次拿起放下、单次晃动不应触发。上下、前后摇动不是本次目标手势。
- 一直摇不会无限重复播放。触发后至少间隔3秒，并且拿稳约0.65秒，才允许下一次完整手势触发。
- 对话和地图页不识别摇晃；开始对话、切页或收到云端情绪时，取消本地摇晃反应和未完成手势。切回来不会补播之前的眩晕。
- 固定竖直倾斜、单击开心、双击惊讶继续沿用；本版没有增加震动或长按操作。

正常幅度手持来回即可，不需要猛甩。如果不容易触发，请反馈次数和方向，我们按手感调阈值。

## 六项验收

| 项目 | 怎么试 | 通过标准 |
|---|---|---|
| 1. 主动触发 | 待机正常眼睛时，左右来回摇约1秒，然后停下 | 出现眩晕，约1～2秒自动回待机；重复尝试几次都能触发 |
| 2. 冷却恢复 | 一直摇约5秒，再拿稳、等至少3秒后重新摇 | 持续摇时不反复重播；拿稳并过冷却后，可再次触发 |
| 3. 避免误触 | 普通左右/前后慢倾斜、拿起放下、单次晃动、拿着走一小段 | 倾斜仍顺畅，不容易无故眩晕；不需要靠切地图恢复 |
| 4. 对话优先 | 眩晕时唤醒；对话过程中摇动；结束对话后再试 | 唤醒和回答正常，眩晕让位于语音；对话中摇动不改变对话表情；回待机后可用新手势触发 |
| 5. 切页取消 | 眩晕中切到地图，在地图页摇，再切回来；也试摇一半就切页 | 地图不受影响，切回来不补播；在语音页重新完整摇动才会触发 |
| 6. 原功能 | 单击/双击、固定竖直倾斜、按键和滑动切页；地图定位/路线/已走变色，持续使用约10分钟 | 原功能正常，无明显音频卡顿、重启或花屏 |

请优先反馈“容易触发还是费劲”“普通拿起或走路是否误触”“眩晕是否正常结束”。电脑模拟信号不能替代真实手持动作验收。

## 开发记录

- 新增 `avatar_shake.h`，借鉴上游 Avatar 的“连续横向反转计数”，在原约50Hz采样任务中识别；通过互斥保护的单个事件交给显示线程，不等待绘制、不排队重播。
- 滤掉慢速重力变化后，横向动态加速度至少0.55g，且为其他方向的至少1.5倍，才算强摆动；至少4次方向交替，相邻间隔100～500ms，整组最多1600ms。数据无效或间隔超过120ms就丢弃未完成手势。
- 触发后3秒冷却，并要求动态加速度连续650ms低于0.18g。已完成事件超过250ms未消费也丢弃，防止忙碌或切页后补播。
- 重力倾斜算法 `avatar_input.h`、BMI270驱动、表情绘制引擎和导航实现与已验收 test04 保持一致；摇晃允许使用超出静态重力范围的有效加速度，单独检测，不改变倾斜滤波。
- 本地摇晃只播放现成 Dizzy 表情一次，不循环等待，也不震动；眩晕期间仍保留冷却跟踪。云端情绪、点按反应、对话和切页可取消本地反应。
- 新增模拟信号测试覆盖连续触发、冷却/拿稳重新触发、弱动作/普通倾斜/单次碰撞/上下前后动作拒绝、断读与状态切换取消、时钟回绕和过期事件；真实桌面 LVGL 测试检查眩晕出现/结束、语音和云端抢占、地图隔离。

串口触发日志为 `Repeated horizontal shake -> DIZZY`。原表情及互动参考继续遵循 AGPL-3.0-or-later，来源说明和许可证随源码保留。验收记录、哈希和回退文件见包内 `build-report.json`。

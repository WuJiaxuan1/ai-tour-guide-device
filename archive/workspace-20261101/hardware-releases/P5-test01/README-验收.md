# P5-test01：左右切页、语音暂停、开机音量 85

日期：2026-10-27。P5 五项已由你确认全部通过，现保留为 P6 回退版本。下面保留当时的安装及验收步骤；最新版本见 `../P6-test01/README-验收.md`。

## 这次能做什么

- 开机配网后进入语音页，用“枫叶精灵”唤醒和对话。
- 正对屏幕，短按右键进入地图页；短按左键返回语音页，切换有平移动画。
- 语音页再按左键、地图页再按右键都停留原页。左键不再启动对话，右键不再调音量，本版不新增长按功能。
- 地图页明确写“地图尚未接入”“此页暂停语音”。当前只是占位页，没有实际地图、定位或路线。
- 切进地图页会结束当前对话、停止唤醒和语音录制、清理待播放声音；回到语音页重新等待唤醒，不续播上一段回答。Wi-Fi 和 App 局域网链路保持可用。
- **每次开机，音量都设为 85（范围 0～100）。** 本次使用中仍可让小智调音量，下次开机再恢复 85。屏幕测试信息中的 `VOL 85` 表示设备当前音量，通常一秒内更新。

你已确认左键在 P4 中是原对话键，因此本版左键对应 GPIO2，右键对应原音量键 GPIO1。配网、激活和升级期间不进入地图页，保证配网提示可见。

## 2. 五项验收

### 第 1 项：开机与音量

配网后应进入语音页，测试信息显示 P5、IP 和 `VOL 85`，原智能体绑定不变。“枫叶精灵”能唤醒并完成一轮对话。

### 第 2 项：左右切页

右键进地图，左键回语音，来回操作二十次。确认：

- 页面方向正确，有滑动效果，地图页显示占位提示。
- 语音页按左键不会开始对话；地图页按右键不会多出第三页或回到语音。
- 再试几次较快的左右交替，不停在半屏、不出现重复界面、花屏或重启。

### 第 3 项：地图页暂停唤醒

进入地图页，说三次“枫叶精灵”，手表不启动对话。再按左键回语音，等待待机后说唤醒词，应正常回应。

### 第 4 项：回答中切页

在语音页唤醒后，让小智讲一段较长的故事。它还在播放时按右键：声音应迅速停止，地图页保持显示。留在地图页约十秒，旧回答不能再次响起，也不能把地图页覆盖。

按左键返回，应处于待机，不续播旧故事。重新说“枫叶精灵”并问新问题，应可正常对话。再试一次在“聆听”状态切入地图，确认返回后可以重新唤醒。

### 第 5 项：连接保持与下次开机恢复 85

在地图页用 P2 App 连续发送十条消息，应全部得到确认，切页不要求重新配网。

回语音页，让小智“把音量调到 30”。观察 `VOL` 是否实际变为 30，以设备显示为准，不只看它口头答应。随后重启手表并重新配网，应回到语音页，音量重新显示 `VOL 85`，再次唤醒可对话。

如果云端没执行音量调节，先反馈这一点和实际 `VOL` 数字，不把测试算作“已经改到 30”。

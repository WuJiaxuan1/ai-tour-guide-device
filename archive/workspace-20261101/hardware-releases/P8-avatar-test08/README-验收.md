# P8-avatar-test08：轻微震动反馈

版本：`2.2.6-p8-avatar08`，基于用户已完整验收的 **test07**。手机不用更新。本版先做震动，下一阶段再做“跟随实际说话节奏动作”；**震感、噪声及收音影响待真机验收**，未自动烧录。

## 哪里会震动

| 操作 | 表现 |
|---|---|
| 待机单击屏幕 | 惊讶表情触发时短震一下，仍需等约0.3秒区分双击 |
| 待机快速双击 | 开心表情触发时短震一下，不按两次分别连震 |
| 从待机唤醒或开始新一轮对话 | 首次进入聆听状态时短震一下，表示已开始听 |
| 同一轮对话中回答完继续聆听 | 不重复震动 |
| 地图页、配网页、拖动/滑动、对话中点按 | 不触发点按震动 |

初始参数为马达PWM强度160/255、目标45ms短脉冲。实际体感取决于外壳、握法、电量，需你反馈太轻/合适/太强。它是“很短一下”，不会持续震动。单击惊讶、双击开心及摇晃眩晕沿用test07。

## 怎样避免卡顿和误触

- 画面只提交请求，独立任务控制马达开关；不在绘图或触摸线程里等待震动结束。
- 震动和结束后约180ms余振期暂停处理倾斜/摇晃输入，清掉未完成手势；表情动画继续。之后自动恢复固定竖直倾斜与摇晃识别，无需切页。
- 切地图、离开正常表情页、改变语音状态时取消过期/待执行请求；快速连续操作不积压一串震动。
- 驱动初始化失败时保留语音、导航和表情；运行时写入失败会停止接受新震动，并继续尝试关闭马达。

## 六项验收

| 项目 | 怎么试 | 通过标准 |
|---|---|---|
| 1. 单击/双击 | 待机分别单击、双击，多试几次 | 单击惊讶、双击开心，各有一次很短的震动；无连续嗡嗡声 |
| 2. 开始对话 | 唤醒“枫叶精灵”，马上说一句话；进行几轮问答，回待机再唤醒 | 每轮对话第一次聆听短震一次，后续不反复震；首句能正常识别，无明显新增收音问题 |
| 3. 马达不触发眩晕 | 拿稳时连续进行点按互动 | 震动本身不使眼睛突然眩晕或乱跳；原眨眼/表情仍流畅 |
| 4. 震后恢复 | 点按震动后，等表情恢复，再倾斜和左右摇晃；不切页重复5轮 | 固定竖直参考正常，摇晃可重复触发，眩晕结束恢复正常 |
| 5. 状态与取消 | 点按后立刻切地图；在地图页点击/滑动；对话中点击 | 不在地图或对话中补震，切页和语音不受影响 |
| 6. 完整回归 | 导航地图、定位点、路线和已走变色；语音/按键/滑动交替使用约10分钟 | 没有明显音频卡顿、重启、花屏或马达不停止 |

优先反馈震感强弱，以及唤醒后立刻说话是否清楚。电脑测试不能验证实际马达起转、机械余振或麦克风拾音。

## 无震感或行为异常时

可在本目录采集20秒日志，期间单击、双击并唤醒一次：

```powershell
& 'D:\Study\yiqifen\stopwatch-custom\.tools\espressif\python_env\idf5.5_py3.12_env\Scripts\python.exe' .\capture_avatar_shake.py --port COM实际端口 --seconds 20
```

日志中的 `StopwatchHaptics` 会记录PWM开/关命令是否得到通信确认；这不等于已经确认马达实际运动。`ShakeDiag` 中 `motor_muted=1` 表示马达防误触屏蔽。脚本只记录表情/马达诊断，不烧录或主动重启。

## 开发交接

- `avatar_haptic.h`：单个待执行请求、150ms过期、取消代次、45ms脉冲与180ms余振期；运行中不延长脉冲，不积压请求；失败后禁止新脉冲并每100ms重试关闭。
- `stopwatch_haptics.*`：复用已初始化I²C总线，配置M5IOE1 PWM1/IO9、200Hz；独立任务执行有界PWM寄存器写入，不在显示锁内执行I²C。
- `avatar_display.*`：点按和每轮对话首次聆听回调、状态取消、线程安全传感器屏蔽。
- `avatar_shake.h`：马达屏蔽单独于页面启用状态，屏蔽前后清空未完成/待显示的摇晃事件；摇晃检测阈值和test07重复触发行为沿用。
- 测试覆盖PWM字节、停止时机、余振期、请求过期/取消、通信延迟/失败重试、时钟回绕，以及真实桌面LVGL点按/聆听/切页和马达误触隔离。固定竖直倾斜、表情引擎及导航核心逐文件核对与test07一致。

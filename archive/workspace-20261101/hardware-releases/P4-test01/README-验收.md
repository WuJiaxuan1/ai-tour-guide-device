每次开机重新配网、原云端绑定、按键和 P2 通信测试保持原有设计。手机继续使用 P2 App，无需更新。当前没有地图页；通过本阶段后再做 P5 页面切换。

## 2. 配网并确认版本

沿用 P3 的同一手机操作：手表开机 → 手机连手表的 `Xiaozhi-…` 热点 → 打开配网页 → 填手机热点名称和密码 → 保存 → 点击“开始连接” → 手机开启自身热点。中间不要重启手表。

联网后手表的通信状态标识应为 P4。在 P2 App 填入手表当前 IP，点击“检查连接”，应显示 `2.2.6-p4-test01`。检查云端仍是原来的设备与智能体。

版本文字只证明程序已更新；第 3 节的唤醒实测才确认新模型确实生效。无需在小智网页上重新配对或更换 MCP 接入点。云端角色自称什么由智能体设定决定，与本地唤醒词不是同一项设置。

## 3. 五项验收

测试唤醒前，请等手表处于待机、没有录音或播放回答。**处于持续对话或聆听中时再次说唤醒词，不算一次新的待机唤醒测试。** 每次结束交互、返回待机后，再测下一次。

| 项目 | 操作 | 记录 / 通过标准 |
|---|---|---|
| 1. 启动与配网 | 按 P3 流程联网，App 检查版本，核对原智能体 | P4 版本正确，原绑定保留，无重启循环 |
| 2. 半米唤醒 | 安静环境，距手表约半米，正常音量说“枫叶精灵”，共十次 | 记录成功几次 / 10；第一版演示目标至少 9/10，不需要刻意大喊或把字拆开 |
| 3. 距离与噪声 | 约一米安静环境测十次；再在普通背景声音下约半米测十次 | 分别记录结果和噪声类型；用于评估适用范围，不预设与安静半米相同的成功率 |
| 4. 误唤醒观察 | 保持待机，正常交谈或播放背景声音五分钟，不说唤醒词 | 记录误唤醒次数；如触发，待它结束回到待机再继续。没有频繁误唤醒；任何误触发请如实反馈 |
| 5. 对话与连接回归 | 唤醒后完成至少三轮对话，App 连续发十条消息；重启配网后再唤醒一次 | 录音播放正常、十条确认齐全、重启后新词仍有效，没有卡死或绑定变化 |

识别率这里只是本次演示测试结果，不代表所有距离、环境下的识别率。“你好小智”已不作为本版本配置的唤醒词；若它仍能稳定唤醒、而新词完全不行，请优先反馈程序和资源是否一起更新。

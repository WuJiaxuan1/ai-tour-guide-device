# P7-test03：发图后闪退修复、全屏地图和当前位置

2026-10-28。用户确认 P7-test02 能保存 Key 并发送真实周边地图，但发送后 App 闪退。本版已完成代码修复、两端构建、离线测试和打包；尚未进行真机复测。

## 改动

- 修复发图成功后绘制手机定位点时，向不可修改 Bitmap 创建 Canvas 的代码错误。改为在独立像素数组中画蓝点，再生成预览图片；不再手动回收仍可能被 ImageView/渲染线程或 SDK 持有的图片。
- 地图显示确认后立即发送最新有效位置，手机预览和手表均显示蓝点。首次无有效 GPS 时明确等待，不以假位置代替。
- 手表真实地图铺满 466×466 圆屏，移除地图页上的大标题、IP/RX/VOL 调试区及底部切页文字，仅保留小型 N/GPS 状态；原按键和左右滑动仍可用。
- 定位点扩大为 24 像素蓝点，带白边；与底图采用同一比例转换坐标。有效位置随移动更新，旧位置过期时隐藏。
- 手机 SDK 使用 480×480 地图视图，发送中央 240×240 区域，避开底部高德标识，并按裁切边界计算经纬度。没有用纯色块涂掉地名或道路。手机原始 SDK 视图仍保留其默认标识；“手表地图预览”展示实际导出的中心区域。
- App 增加“查看上次闪退记录”。若仍退出，可重新打开后查看记录并反馈。

本版传输分辨率仍为 240×240，由手表放大铺满圆屏，不是原生 466×466 高精度底图。这保持了已验收的传输大小和内存预算。实际文字清晰度、SDK 标识是否完全位于裁切区外，以及圆屏边缘显示均需此次真机检查。

## 安装：这次手机和手表都更新

### 手机

将本目录 `maple-map-P7-test03.apk` 传到手机覆盖安装，不卸载、不清数据。包名、签名与 SHA1 没变，P7-test02 已保存的 Key 应保留。首页应显示 P7-test03。

### 手表

连接 StopWatch 数据线，确认实际 COM 端口，关闭占用串口的软件。PowerShell 执行，替换 `COM实际端口`：

```powershell
Set-Location 'D:\Study\yiqifen\stopwatch-nav\releases\P7-test03'
& 'D:\Study\yiqifen\stopwatch-custom\.venv-flash\Scripts\python.exe' .\flash_p7.py --check-files
& 'D:\Study\yiqifen\stopwatch-custom\.venv-flash\Scripts\python.exe' .\flash_p7.py --flash --port COM实际端口
```

脚本只写核对后的当前应用槽和配套资源，不全片擦除、不写 NVS/分区表/bootloader/OTA 选择。手表版本应为 `2.2.6-p7-test03`。

沿用既有配网流程：手机连手表热点 → 输入手机热点名称/密码 → 保存 → 开始连接 → 手机开自身热点，中间不重启。每次开机音量仍为 85，唤醒词“枫叶精灵”，云端绑定应保持。

## 本轮五项验收

1. **首图后不闪退。** 手机 App 前台、GPS 有效，手表进入地图页，开始同步。地图装载后观察至少两分钟，手机正常显示预览，位置计数持续增加。再手动“重新获取周边底图”五次，每次等上一张完成，确认不退出。
2. **地图占满圆屏。** 手表地图应铺到圆屏可见边缘，无原来的小方图边框、大标题或底部调试区。查看道路方向与手机“手表地图预览”是否一致；圆屏会自然裁掉方图四角。
3. **标识和地图内容。** 手表导出的中心区域不应带原来底部的高德标识；地名、道路不应被涂块遮住。手机上方的原始地图视图包含更大范围且仍可见 SDK 标识，这是预期；请对照下方的手表预览。
4. **当前位置。** 手机有不差于 50m、年龄不超过 15 秒的真实 GPS 时，手机预览和手表均应有蓝点。静止时结合精度判断位置，步行 100～300m 检查蓝点方向和换底图；放大后不应偏到别的道路。第一次等待定位和旧位置过期时不显示假点。
5. **切页和停止恢复。** 回语音页唤醒并对话，返回地图恢复定位；停止手机同步后约 15 秒加一次刷新周期内旧点隐藏，完整地图可以保留。重新开始可恢复。App 仍要求前台运行，锁屏/离开页面会暂停。

## 如果仍闪退

重新打开 App，点击下方“查看上次闪退记录”，发出其中异常类型和堆栈文字，或拍照。记录可能是修复前留下的旧记录，请带上记录时间。可先清除旧记录，再重现一次以便区分。

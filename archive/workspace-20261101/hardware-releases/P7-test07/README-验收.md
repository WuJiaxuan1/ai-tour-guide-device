# P7-test07：方案二——地图块、提前取图、移动窗口

本版**手机 App 和手表固件都要更新**。沿用你选择的 **14.0＋隐藏地图文字**；覆盖安装会保留已保存的选择和高德 Key。没有保存过设置时也默认使用这两项。

## 会看到什么

- 手机准备一块 **480×480** 的地图，手表显示其中 **240×240** 的窗口，再铺满圆屏。屏幕可见范围仍对应原来的 14.0，额外地图放在屏幕外供移动使用。
- 正常走动时，蓝点保持在屏幕中央附近，周围道路随位置移动；相邻真实定位之间增加约 320ms 的平移动画。
- 离缓存地图边缘还有余量时就准备下一块；旧图在取图期间仍可移动。新块完整收到后按同一地理位置对齐替换。
- 若下载太慢、突然跳到远处或断网，可能用完缓存。此时窗口停在地图边缘，蓝点按真实位置移动；超出底图或定位过期则隐藏，不假装一直居中。

这采用 MotoNav `MapFeeder` 的“当前块＋提前准备下一块＋确认后替换”思路。当前是重叠的大图块，不是九宫格瓦片库，也不含路线、转向、地图旋转或服务器。

## 3. 联调与五项验收

1. **首图与范围**：手表配到手机热点，打开地图页。App 确认 IP、14.0、隐藏地图文字，开始同步，等 GPS 有效和地图块显示。范围应与上一版 14.0 接近，不能把整个大块缩进圆屏。观察两分钟，无闪退或重启。
2. **窗口移动**：在室外沿一条路走几十米到一百多米，看蓝点是否在中央附近、道路是否移动；App 的位置次数应增长，地图块数量可以暂时不变。比例尺较远或 GPS 抖动会使少量步行不明显。
3. **提前下载和换块**：继续走到 App 显示“正在预取”并且地图块数量增加。取图时旧图不能消失；新块接上时位置、道路方向和比例应接近一致。14.0 时可能要走较远才能触发；为了缩短测试，可临时调到16.0，验证换块后恢复14.0。上方手机地图此时可能提前偏向前方，下方预览显示当前手表窗口。
4. **信号与恢复**：停止同步后，底图保留，旧定位点最迟约16秒隐藏；点开始可恢复。或暂时关闭手机移动数据（保留热点），缓存内仍可移动，需新图时可能等待，恢复数据后应继续。不要把“缓存内可用”当作完整离线地图。
5. **语音与设置**：切语音页唤醒并对话，再回地图页应恢复同步。退出再打开 App，14.0 和隐藏文字仍保留；手机 App 在后台/锁屏仍会停止，返回需点开始。

每个地图块约450KiB，是上一版的四倍；上传期间定位发送可能短暂停顿，实际时间取决于热点链路。地图页继续暂停语音，下载仅在手机 App 前台进行。此版没有把 GPS 预测当作真实位置发送：移动方向只用于决定下一块取哪里。

## 3. 连接拓扑

1. Zenfone 开启手机热点，并确保手机可上网。
2. StopWatch 连接这个手机热点。若它仍连接家里 Wi-Fi，先用原有小智配网方式切换到手机热点。
3. 等手表显示类似 `P2 192.168.43.123:8765` 的信息。
4. 在手机 App 中只输入 `192.168.43.123` 这样的 IP，不输入 `http://` 或 `:8765`。
5. 点击“检查连接”，应显示“通信可用”及 `2.2.6-p2-test01`。

手机是热点提供方，不需要再连接自己创建的热点。此时手机也不应连接手表的配网热点；那是配网阶段使用的另一条链路。

## 请验收五项

1. **联网与界面**：手表仍绑定原智能体，显示 P2 地址；App 显示“通信可用”。
2. **单条消息**：点击“发送 1 条测试消息”，App 显示对应编号“已确认”和耗时；手表 RX 与 total 更新。
3. **十条消息**：点击“连续发送 10 条”，约数秒完成；本组获得 10 个确认。若之前发送过 1 条，本次累计应为 11 条、失败 0 条，最后编号通常为 11。状态轮询不增加计数。
4. **语音未被破坏**：发送完成后，用“你好小智”完成至少一轮对话，录音、播放正常，绑定不变。
5. **恢复连接**：关闭再开启手机热点，等手表重新连上。App 若一直在前台且 IP 未变，应恢复可用；如因进入系统设置离开了 App，返回后点击“检查连接”；若 IP 变化，先输入新 IP。再次发送 1 条，应能收到确认。

第一版允许手动输入 IP，不要求自动发现设备。App 离开测试页或进入后台会暂停检测，当前不把锁屏后台运行作为验收条件。

## 如果失败，怎样反馈

直接按下面模板填写即可：

```text
第几项失败：
手表显示的 P2 IP：
App 提示或报错：
本次确认数量 / 失败数量：
小智语音是否仍正常：
是否换过热点 / IP / 进入过后台：
截图或相关日志：
```

常见分支：

- 手表没有 P2 字样：先检查是否确实更新了固件。
- 手表显示 waiting for Wi-Fi：先完成手机热点连接。
- 手表显示 server error：保留现象，重启一次并反馈，不把它算通过。
- App 无法连接但小智可对话：上网已通，局域网链路仍需排查；核对手机热点、设备 IP、P2 固件及 VPN/路由设置。
- 可用手机浏览器打开 `http://手表IP:8765/api/v1/status` 辅助判断。出现包含 `qixia-stopwatch` 的 JSON，表示浏览器可以到达设备；这一步不要求用户理解全部字段。
- App 未获确认时，本组会停止，不自动重发；手表有时已收到但回复没到手机，保留双方计数有助于定位问题。

## 2. 怎么使用

1. 手表连接手机热点，进入地图页；App 点“开始定位和地图同步”，等待有效 GPS 和底图。
2. 点“搜索目的地并规划步行路线”，输入附近地点，必要时填写城市，从列表核对地址后选择。建议先选几百米内、步行道路清楚的地点。
3. 等待规划完成。手机显示目的地、规划总长和预计总时长，随后同步到手表。
4. 手表显示彩色路线、圆形当前位置点、方形目的地标记。终点不在当前屏幕范围内时不会强行显示在边缘；走近后才可看到。整条路线已传输，但屏幕继续显示当前位置附近窗口。
5. 在“路线配色”中调整路线、位置点、终点和描边，使用RGB滑条、预设色或输入 #RRGGBB，点“应用并保存”。线宽滑条松手后应用，范围2～16像素。
6. “取消路线 / 返回巡航”清除手表路线和终点，保留底图和定位。

“已走路线颜色”可调、保存并在配色样例左段预览，但本版尚不计算行走进度，实际地图保持整条路线同色。路线规划总长不是实时剩余距离。本版无转向、到达判断或偏航重算；改变目的地需要重新选择。退出App后重开需重新选路线，配色会保留。

已有 Android Key 会同时用于搜索与步行算路，不必把 Key 发给他人。地图能显示不代表这些服务也有权限或额度。若出现错误码，请记录数字和操作步骤；坐标入口可以绕开地点搜索，但依然需要真实步行算路成功，不会画直线充当路线。

## 3. 六项真机验收

1. **原功能回归**：14.0、隐藏文字、GPS点、地图移动与预取正常，无闪退/重启。
2. **选点与路线**：搜索附近目的地，手机规划成功，手表出现贴合道路的路线；靠近终点时方形标记位置合理。再用高德坐标入口检查同样可算路。
3. **配色与粗细**：分别改变路线、定位、终点、描边，手表同步；地图块计数无需因调色而增长（正常预取另计）。颜色保存后重开仍保留；已走颜色只检查样例。
4. **走动与换块**：路线和道路同步移动，换块后继续对齐，无横穿屏幕的错误连线或明显漂移。可临时16.0缩短换块测试距离，随后恢复14.0。
5. **改目的地与取消**：选择另一个附近目的地，旧路线被替换；取消后线和终点都消失，定位与地图仍正常。算路失败时保留此前成功的路线并提示失败。
6. **切页与恢复**：语音页可正常唤醒对话，返回地图页路线恢复；停止同步或定位过期后圆点隐藏、静态路线保留，重新开始可恢复。手机锁屏/切后台仍会停止，返回需点开始。

反馈时注明第几项失败、App提示或高德错误码、当时缩放和定位精度；路线偏移可同时拍手机下方预览和手表。

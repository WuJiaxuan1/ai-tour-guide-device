# P8-avatar-test04：固定竖直参考

版本：`2.2.6-p8-avatar04`。手机继续使用现有 App，无需更新。本版针对 test03“感觉没有改进”的反馈，取消动态校准，改用固定竖直参考。电脑构建和回归测试结果见包内日志；**真机流畅度与方向待验收**，没有自动烧录。

## 使用效果

把设备按正常方向拿好：屏幕竖直、正对自己、顶部朝上。这个姿态固定为中间位置，不再把开机或切页时的握姿当作中心。

- 不用先静止等待校准。首次有效重力读数即可产生倾斜目标；眼睛本身仍有平滑过渡。
- 左右歪、前后倾会改变眼神；保持歪着时不会自动重新居中。
- 放在桌面开机，之后拿到竖直姿态，眼睛应回到中间附近，不需要切地图再回来。
- 切页或断读恢复后，仍按同一套竖直参考响应。
- 暂时去掉陀螺仪瞬时偏移，仅使用重力方向；正常眨眼、待机小动作和对话表情仍然保留。

这里的“居中”是倾斜带来的偏移归零，眼睛仍可能有原来的待机小动作，并非完全固定不动。设备平放时已经远离竖直参考，视线达到上下限属于预期，不是要把平放也校准为中间。

## 六项验收

| 项目 | 操作 | 通过标准 |
|---|---|---|
| 1. 桌面开机再拿起 | 在桌面完成开机配网，出现表情后拿到竖直姿态，不切页 | 眼睛平滑回到中间附近，可直接开始倾斜，无需静止校准 |
| 2. 四方向 | 竖直拿好，再分别左右歪、前后倾约10～20度，再回正 | 四个方向都响应，前后动作有区别；回正后恢复中间附近，无明显一顿一顿 |
| 3. 保持倾斜 | 歪约15～20度保持3～5秒 | 偏移保持，不自行重新居中；保持到10秒也不改变参考 |
| 4. 切页比较 | 保持同一握姿切地图，再返回；再比较刚开机与返回后 | 同一姿态对应基本相同偏移，返回后无需校准，流畅程度没有明显差别 |
| 5. 点按与对话 | 待机单击、双击；唤醒后对话，同时轻微倾斜 | 开心/惊讶正常；对话和语音状态表情正常，倾斜幅度较小，无明显新增声音卡顿 |
| 6. 导航与持续使用 | 按键/滑动切页，手机同步地图路线及已走变色，多次往返并使用约10分钟 | 导航正常，地图无表情覆盖，返回可唤醒；无重启或花屏 |

优先反馈第1～4项。如果方向不合适，请直接描述“向左歪时眼睛向右”“向前和向后都没有变化”等。若仍然只有切页后才顺，请说明是跟随延迟、视线顶在一边，还是连续移动时一顿一顿；后续应记录实际采样/绘制间隔，不把电脑测试通过当作已解决真机卡顿。

## 开发说明

参考 M5Stack 官方 [StopWatch HAL](https://github.com/m5stack/M5StopWatch-UserDemo/blob/main/main/hal/hal_imu.cpp) 的轴交换方式：原始 Y 对应屏幕横向，X 对应屏幕纵向，Z 垂直于屏幕。算法分别计算横向和深度方向相对重力的有符号倾角，竖直时二者为零；不是简单固定旧版加速度基准。采用绝对倾角，不实现倒置时自动旋转屏幕，也不提供指南针方向。

当前参数集中于 `avatar_input.h`：

| 参数 | 当前值 | 用途 |
|---|---|---|
| 中心死区 | 1.5° | 减少自然轻抖，越过死区后连续增加偏移 |
| 满幅角度 | 25° | 约25°达到最大偏移，继续倾斜不越界 |
| 输入平滑时间常数 | 80ms | 按实际间隔平滑，而非按固定样本数 |
| IMU采样周期目标 | 20ms | 沿用独立采样和最新有效读数邮箱 |
| 表情定时周期 | 40ms | 沿用原绘制节奏；未测量真机帧率 |

`Reset()` 只清平滑历史，不学习任何新的参考姿态。无效重力数据不会刷新最后有效读数时间；超过500ms缺数据时目标回中，超过2秒清平滑历史，恢复后无需校准。驱动读取只要求加速度数据就绪，不再等待陀螺仪数据就绪；传感器配置与共享总线方式沿用。

测试覆盖歪着开机、桌面拿起、长时间保持偏移、切页/长间隔后的参考一致性、四方向和极端姿态、死区连续性、不同采样间隔平滑一致性、陀螺仪不参与、无效重力与邮箱过期；并回归原点按、真实 LVGL 表情/地图/路线/切页和设备协议。

串口首次有效输入会记录 `IMU fixed vertical reference active (no calibration/gyro lead)` 及三个加速度值，用于需要时核对握持方向。许可、来源声明、构建源码和哈希随包提供；原表情移植沿用 AGPL-3.0-or-later。

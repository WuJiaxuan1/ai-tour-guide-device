# P8-avatar-test03：倾斜跟随平滑调整

版本：`2.2.6-p8-avatar03`。针对“刚开机倾斜不顺，切到地图再回来就顺了”的反馈修改。电脑测试和构建已完成，**实际手感仍待你验收**；未自动烧录。手机 App 无需更新。

## 本次调整

1. 传感器按约20毫秒的固定节奏采样，不再等屏幕画完才继续读取。画面只取最新读数，避免积压旧动作。表情仍按40毫秒定时更新，不增加整屏刷新频率；实际帧率未测量。
2. 短暂缺少读数或受到晃动时，保留已校准的姿态，不再因为250毫秒的中断重新等待校准。超过500毫秒未收到数据，视线目标回中；超过2秒才清空校准。平滑程度按经过的时间计算，减少采样间隔波动的影响。
3. 从桌面拿起、握持姿态变化很大时，拿稳约1秒会自动重新居中。普通10～25度倾斜仍保留眼神偏移，不会刚歪过去就回正。

这几处是根据代码和现象定位的可疑环节，尚无真机采样记录证明唯一原因。进入语音页时仍请按平时姿态拿好、稳定约1秒；持续晃动会延后校准。大幅改变姿态后短暂回正属于重新校准，不是丢失响应。

单击开心、双击惊讶、对话时减小倾斜幅度、按键和左右滑动切页继续保留。唤醒词、开机配网、音量85、原绑定以及导航功能沿用原版。

## 六项验收

| 项目 | 怎么试 | 期望结果 |
|---|---|---|
| 1. 刚开机，不切页 | 重启配网后拿稳1秒，先不去地图页，慢慢左右、前后倾斜 | 跟随连续，没有此前明显一顿一顿的感觉；眨眼正常 |
| 2. 前后比较 | 切地图再切回来，拿稳1秒，重复同样动作 | 与第1项手感接近，不需要靠切页“恢复流畅” |
| 3. 桌面拿起 | 在桌面配网并等待表情出现，再拿起到平时姿态，稳定1～2秒 | 自动适应新握姿，然后轻微倾斜能正常响应；左右都可移动，不长期顶在一侧 |
| 4. 持续倾斜 | 缓慢歪10～25度，保持3秒，再回到原姿态；轻晃一下后再慢慢倾斜 | 保持歪着时仍偏向该侧；回正平滑；轻晃后不必切页才能继续跟随 |
| 5. 点按与对话 | 待机单击、双击；唤醒“枫叶精灵”并交谈，同时轻微倾斜 | 开心/惊讶正常；对话正常、倾斜幅度较小，无明显新增声音卡顿；对话中点按不触发表情 |
| 6. 导航与切页 | 按键、滑动切页；手机同步地图、路线、已走变色，多次往返并使用约10分钟 | 地图路线正常、无表情覆盖，回来仍可唤醒；无重启、花屏或越来越卡 |

## 已实现并通过真机验收

### StopWatch 随身终端
- 连接小智云端，使用“枫叶精灵”唤醒并进行语音对话，保留原有智能体绑定。
- 小智待机页短按左键主动开始自动聆听，无需喊唤醒词；地图页左键只返回，连接/聆听/回答时重复按不结束对话。
- 每次开机重新配网，方便连接不同游客的手机热点；默认音量为85。
- 支持语音页和地图页，通过按键或左右滑动切换；地图页暂停语音。
- 地图铺满圆屏，显示周边地图和当前位置；沿用缩放14.0、隐藏地图文字的效果。
- 配网完成后，语音页全屏显示黑底白色眼睛，隐藏上下文字、字幕和设备状态文字；配网、激活和错误提示保留原界面。
- 支持固定竖直参考的左右/前后倾斜跟随，无需开机或切页校准；待机单击惊讶、双击开心，对话时倾斜幅度减小。
- 待机单击、双击和每轮对话首次聆听时有短震反馈；震动及余振期隔离倾斜/摇晃输入，之后自动恢复。
- 待机连续左右摇晃触发眩晕，播完自动恢复新一轮识别；不需切地图或拿稳解锁，对话和切页优先。
- 表情随待机、聆听、等待回复和说话变化；云端发来情绪时显示笑眼、惊讶、生气等，播完回到当前状态。
- 显示前往目的地的路线和终点；走过的路线变色，切页、换地图块和调色后保留进度。

### 配套 Android App
- 获取手机位置，使用高德地图 SDK 渲染周边地图。
- 通过手机热点局域网，将地图和位置发送给 StopWatch。
- 支持配置高德 Key、设备 IP、地图缩放和显示选项，并保存设置。
- 支持搜索或坐标选点、规划步行路线，分别传输底图、路线和定位进度。
- 可调整并保存路线、已走路线、定位点、终点和描边颜色，以及路线线宽。

## 已验收的地图与表情能力

- **地图块与窗口移动**：手机准备480×480地图块，手表显示其中240×240窗口并铺满屏幕；随定位移动窗口，接近边缘提前取图并对齐换块。
- **路线独立绘制**：底图和路线分开传输，调色不用重传底图；手机根据有效 GPS 更新已走进度，手表保留已走前缀；重新规划时重置进度。
- **全屏动态表情**：复用 Avatar 项目的关键帧、眨眼和眼神动作，通过现有 LVGL 显示；切到地图页暂停表情动画。

P8-avatar-test10 已完成编译及电脑测试，并由用户确认开机唤醒、对话后再唤醒、地图返回唤醒、中途切页、左键混用和原功能回归六项通过。验收以用户反馈为依据；尚未独立测量帧率或多设备长期稳定性。原固件与资源保持不变，已安装该版的设备无需再次刷机；手机继续用 P8-test02。

## 当前如何配合

```text
语音：游客 → StopWatch → 手机热点上网 → 小智云端 → 手表播放回答
地图：手机定位＋高德地图 → Android App → 热点局域网 → 手表显示
```

StopWatch 没有独立 GPS，位置来自手机。当前地图链路不依赖自建服务器；手机 App 需保持前台运行，切后台或锁屏会停止同步，返回后需重新开始。

## 功能边界与后续对接

- 已有路线显示与已走变色，尚无转向提示、到达提示和偏航重算。
- 说话表情随回复状态变化，尚未按音量或逐字同步；云端不保证每次回答都发送指定情绪。
- 本轮验收使用 Android App → 手表的导航链路。网页／服务器接入导航、网页业务数据与小智共享会话不属于此次表情验收范围，需要分别联调确认。
- 后续新功能从这个版本继续开发，生成新版本并把当前包作为回退基线。

### 代码从哪里看

- Android 主要代码：`android/app/src/main/java/com/example/motonav/`，先看 `SurroundingMapActivity.kt`（流程）、`PhoneMapRenderer.kt`（地图生成）、`MapChunkPolicy.kt`（预取）、`LocalLinkClient.kt`（设备通信）。路线功能另看 `WalkingRoutePlanner.kt`、`WalkingRoute.kt`、`WalkingRouteControls.kt`。代码目录仍保留上游名称，安装包名为 `com.qixia.stopwatchnav`。
- 固件板级代码：`firmware/main/boards/m5stack-stopwatch/`，先看 `local_link_server.cc`（接收）、`map_frame.h`（地图协议）、`stopwatch_pages.h`（绘制与切页）。表情入口为 `m5stack_stopwatch.cc`，动画与绘制为 `avatar_engine.*`、`avatar_display.*`、`avatar_surface.h`。交接时保留完整工程，不只复制这些文件。

### 换电脑开发需要注意

- 构建入口为 `stopwatch-nav/tools/build.ps1`；当前引用同级 `stopwatch-custom/` 内的 ESP-IDF 5.5.2 工具链，以及 `MotoNav-main/.tools/` 内的 JDK 21、Android SDK 和 Gradle 缓存。队友需安装相应环境并调整路径，源码不是复制后立即可编译。
- 保留 Gradle Wrapper、构建配置、依赖锁定文件、固件分区与板级配置；不必交接 `build/`、`.gradle/` 等缓存。`android/local.properties` 里的 SDK 路径需按接收电脑重配。
- 高德 Key 需配置匹配的包名与签名 SHA-1；重新签名可能影响地图鉴权及覆盖安装。需要延续签名时，签名材料单独交接。
- 小智接入令牌、Key、Wi-Fi 密码和签名私钥不放进公开源码包；由对应负责人单独配置。发布目录中的源码快照用于追溯，不能替代完整源码工程。

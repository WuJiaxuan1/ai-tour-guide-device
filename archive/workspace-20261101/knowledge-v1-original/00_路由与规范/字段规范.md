# 字段规范

| 字段 | 作用 | 必填 |
|---|---|---|
| id | 全局唯一记录ID | 是 |
| library_id | 指定所属库，防止跨库污染 | 是 |
| knowledge_type | 记录类型 | 是 |
| name | 标题或实体主名 | 是 |
| content | 可检索正文 | 是 |
| source_type | 官方快照、地图API、UGC、AI整理等 | 建议 |
| source_name | 可追溯来源 | 建议 |
| captured_at | 采集日期 | 动态信息必填 |
| valid_from / valid_until | 生效与失效时间 | 动态信息必填 |
| verification_status | 已核验、官方快照、待核验等 | 是 |
| confidence | high / medium / low | 是 |
| aliases | 别名索引 | POI建议 |
| warnings | 回答限制与风险 | 有风险时必填 |

一条记录只讲一件事。动态信息不与静态讲解写在同一条记录中。

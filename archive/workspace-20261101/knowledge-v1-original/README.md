# 栖霞山知识库 v1.0

本版本将现有资料按可信度、时效和调用场景拆成八个生产知识库，并设置一个后台待核验库。原始资料没有删除或覆盖。

## 最重要的使用要求

**不要把整个目录作为一个知识库上传。** 必须分别建立KB01-KB08，才能避免官方事实、动态快照、候选路线和UGC经验相互污染。KB09只供维护人员使用。

## 文件格式

- Markdown：适合直接上传到支持文档检索的平台。
- JSONL：一行一条记录，适合向量库、RAG后台或程序导入。
- manifest.json：程序和人工使用的总清单。
- knowledge_record.schema.json：统一字段规范。

# Changelog

## 2026-11-01 — 结束游览入口与设备名称
- 结束游览成功后打开历史行程，可继续选择游览报告或专属手账。
- 前端界面与导出记录中的“小智”统一显示为“枫叶精灵”，配对接口不变。

## 本地待验收 — 2026-11-01 功能入口整理

- 接驳车移动到探索的“游客服务”分类；“我的路线”标题旁只保留历史行程。
- 每条历史行程增加游览报告、专属手账两个功能块。报告读取所选行程的快照并支持图片导出，管理/删除入口保留在报告内；手账标明对应行程，保留现有本地制作方式。

## 本地待验收 — 2026-11-01 专属路线界面整理

- 合并定位缺失、暂停和道路估算的重复提示；下一站名称、导航、到达与跳过操作放入独立卡片。
- 规划后的完整途经顺序改为可展开查看，避免与已选景点列表同时重复展示。
- 小智连接改为两步配对卡片，统一暖色圆角样式，补齐数字输入、回车提交、连接中、内联错误、成功和到期提示；保留原配对接口。
- 手机窄屏采用整行输入和连接按钮；减少开发说明对游客操作的干扰。

## 本地待验收 — 2026-11-01 出入口与路线地图

- 官方推荐移除无坐标的途经景点；西门、南门统一使用对应高德售票处坐标。
- 推荐向导首步改为“出入口”，分别选择进入和离开的门，允许同门往返；专属路线、道路规划、保存行程保持所选首尾。
- 我的路线地图沿用探索页的无数字圆点；绿色箭头表示起点、橙色旗帜表示终点，同门往返时并排显示。
- 换门后使旧道路结果失效并重新规划；补全 R06 用户所选出口时保留最后的太虚亭。

## 0.5.1 — 2026-10-30

- 官方推荐改为入口、时长、体力、同行四步胶囊向导；每步可跳过，老人或儿童同行会自动按节省体力匹配，推荐路线可直接加入“专属路线”。
- “专属路线”支持固定出入口、增删景点后的高德步行道路规划、真实路线几何和开始游览；未核验的官方点位继续明确提示，不生成直线假路径。
- 顶部固定地图缩略图，分类栏随页面滚动；接驳车卡片默认收起，点击后展开站点和运营信息。
- 统一暖红、枫叶红和浅黄色视觉令牌与微软雅黑回退字体；景点卡片按实拍、占位图、宗教分组并结合定位排序。
- 新增本地专属手账：照片只在浏览器预览，播放处理动画后展示固定纪念卡并可下载。

## 0.5.0 — 2026-10-30

- 我的路线重建为官方推荐、自选地点和接驳车：导入 8 条路线、11 组已验证筛选、6 条景区内及 2 条景区外单程线路；明确区分无匹配和未验证。
- 保留重复停靠、官方时长与逐站停留差异；R05 数量冲突、R06 返程缺失均展示，未知位置和道路不生成替代坐标或直线导航。
- 自选以固定出入口、已映射预设点位池和已验证有向矩阵为边界；确定性串联，缺资料时保留选点并展示覆盖最多的官方路线参考。不再从新界面调用实时最短路。
- 规则知识问答承接景点指代、时间/偏好及逐轮路线筛选，返回来源与上下文；计划复用小智但文字通道尚未接入，不宣称大模型已接通。
- 按展示尺寸生成内容哈希 WebP；轻量缺图回退、图库重试、报告用优化图、缩小网站图标。首屏中文变体字库保留完整字形按需回退。
- Node 静态服务支持 gzip、内容哈希长期缓存、ETag/304、HEAD 和 WAV Range；构建/启动开发页会生成图片衍生文件，原图与音频不动。
- 修复返回同地点的独立到访/照片记录；能力接口明确 Android 依赖和未接通的手表路线 ACK。正式道路、小智网页通道、硬件配对及互动彩蛋仍待团队联调。

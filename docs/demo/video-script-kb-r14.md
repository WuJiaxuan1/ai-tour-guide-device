# 路演视频展示顺序：网页 + 小智

目标时长约 3 分钟。主线：**网页选路 → 小智同行 → 两端同步 → 栖霞寺沉浸 → 留下行程记录**。重点拍一个完整闭环，功能异常和详细设置留给验收，不必全部放进路演视频。

## 开拍前

打开 https://43.160.252.245/?v=kb-r14 ，清理画面上的无关弹层，确认手机定位和小智网络/音量。用新的测试行程；R02 条件可选西门→半日→轻松休闲→同行未选择。设备配对提前完成或另录短镜头，成片遮挡有效配对码。

手机录屏展示页面，另一台手机横拍“操作者 + 小智实物 + 网页”并收录小智原声。固定报告/手账不是实时生成结果；不把预录讲解配音伪装成设备现场回答。模型等待可适当剪短，在同一问答内保留真实问题和真实回答。

## 室内拍摄替代方案

如果没有在栖霞寺附近，1:45–2:25 直接说“这个景点有沉浸体验吗”，然后手动点击栖霞寺标签；字幕写“手动打开沉浸体验”。不要录成“系统识别我已到寺庙”或“设备主动提醒”。其余选路、配对、手动到访同步、知识问答和存档可以在室内真实演示。

如果后续补拍景区现场：新行程含栖霞寺、保持手机前台、允许定位、不要提前打开体验；满足接近条件后才能拍自动弹窗。小智提示仍需要先提问。手机定位失败时可坦诚展示缺定位提示，不拼接成已成功定位。

## 可选加镜头，不作为主线卖点

- 5 秒：对小智说“请记住这条旅行感受：我最喜欢明镜湖”。只能说明已保存明确感受，不能紧接固定报告暗示它生成了个性化摘要。
- 5 秒：固定报告 PNG 导出。字幕写“报告模板展示”，不说实际统计。
- 手账建议暂不进入主视频；若展示，标注“固定纪念卡演示”，不说上传照片已被 AI 转为贴纸。

当前不使用的宣传语：“自动播放高德转弯语音”“无需提问主动讲解”“实时掌握红叶和活动”“自动生成真实旅行总结”“任意照片生成 AI 贴纸”。这些均不是本版已完成能力。

# 枫叶精灵问卷与模拟可视化

本目录归档问卷设计、76份模拟答卷、统计明细和展示图。所有答卷由程序生成，没有真实受访者，也没有提交问卷星。图表只描述这份合成数据，不构成真实游客需求证据。

## 文件用途

| 文件 | 用途 |
|---|---|
| `枫叶精灵-76份模拟答卷.xlsx` | 原始76条模拟答卷及题目编码说明，迁移时保持原始字节 |
| `questionnaire.json` | 新版问卷14题、完整选项、来源与显示／互斥规则 |
| `选项统计明细.csv` | 14题×4选项的56行统计，包含人数、分母、比例与跳过人数 |
| `问卷可视化报告-模拟数据.pdf` | 16:9横版六页报告，文字可检索，字体嵌入 |
| `figures/` | 1张总览与5张专题图，各有PNG/SVG；另有一张供PPT右侧使用的透明背景组合图 |
| `scripts/` | 原模拟生成脚本、统计制图脚本与Python依赖版本 |
| `visitor-survey-final-20261031.md` | 14题录入稿及设置说明 |

当前问卷题目以 `questionnaire.json` 和Excel中的题目说明为准。早期审查稿不是当前题目版本。公开填写页为 <https://v.wjx.cn/vm/Y70F5Zn.aspx>，本次使用2026-10-31已读取的题目，不读取真实答卷。

## 统计口径

- 总样本76条，均标记“模拟数据”。记录ID为SIM编号；生成日期不是调查提交时间。
- Q1、Q2、Q7—Q14的分母为76。Q3排除16条独游记录，分母60。Q4—Q6排除14条没有近期经历的记录，分母62。
- 单选题为Q1、Q2、Q12；其余为多选。多选以分号分隔，按选择该选项的记录人数计数，不按总勾选次数计数。
- 空白代表按逻辑跳过，或可选补充未填写；D不是缺失值。多选比例合计可能超过100%。
- Q4—Q11、Q13—Q14的D与其他选项互斥；Q3的D不互斥。
- 总览的功能类别兴趣为同题A/B/C至少选择一项的记录数，每条最多计1次。不同类别之间不能相加，也不是“优先级第一”的比例。
- Q12四类分别展示：愿意19人、特定场景愿意19人、不愿意20人、先体验18人。最后一类不计入愿意。
- 合并措辞的选项只支持大类解释，不能拆算重量、续航、隐私等未单独询问的比例。
- 不进行显著性检验、置信区间估计或真实游客总体推断，不推断购买率、付费意愿或使用效果。

生成使用固定种子20261031、六类人为设定的场景参数，以及预设Q1/Q2分布。完整参数保存在Excel说明页和生成脚本中，均未用真实游客数据校准。脚本整理后已逐字段比对原Excel，76条记录全部一致。

## 复现

从项目根目录运行。Python制图脚本直接读取本目录Excel和题目定义，不修改原始答案。

```powershell
# 先用项目已有Python环境安装 scripts/requirements.txt 中的依赖。
# 临时依赖建议安装到项目 .local-work/survey-figures/deps，禁用pip缓存。
$env:PYTHONPATH = (Resolve-Path '.local-work/survey-figures/deps').Path
$env:PYTHONDONTWRITEBYTECODE = '1'
python -B docs/requirements/visitor-survey/scripts/render-charts.py
```

脚本将Matplotlib配置、字体缓存和临时文件定向到项目 `.local-work/survey-figures/`。Windows默认读取微软雅黑；其他环境可通过 `SURVEY_FONT` 指向已有中文字体。需要先创建依赖目录并安装依赖，示例中的 `python` 应替换为实际可用的Python可执行文件。

原模拟生成脚本使用 `@oai/artifact-tool`，需要已有该依赖的Node环境；在Codex中可使用bundled runtime，将其依赖目录通过 `NODE_PATH` 提供。`--verify` 仅输出生成记录，正常模式遇到已有Excel会中止，避免覆盖已确认答卷。

```powershell
node docs/requirements/visitor-survey/scripts/generate-simulation.mjs --verify
```

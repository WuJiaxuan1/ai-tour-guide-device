## 配置和运行

私有配置在 `/etc/qixia-guide/mcp.env`，权限600，包含MCP_ENDPOINT与QIXIA_API_BASE_URL=http://127.0.0.1:18787。由systemd读取；不向队友公开token，不把此文件放源代码包。网站原有高德配置保持原状。

已授权服务器运维者可执行：

```bash
sudo systemctl status qixia-mcp.service --no-pager
sudo journalctl -u qixia-mcp.service -n 40 --no-pager
sudo systemctl restart qixia-mcp.service
```

日志需要sudo；普通用户journalctl可能看不到系统日志。每次SSH操作仍遵循项目ssh-operation-logging技能，使用原wujiaxuan身份。不要同时从队友电脑连接同一个MCP接入点。

MCP故障时可独立回退：`sudo systemctl disable --now qixia-mcp.service`。网页服务仍继续运行。此为首个服务器MCP release，没有旧MCP版本可直接切回；可在修复后重启，或显式停服务器桥后临时恢复单台本地桥。未来更新MCP应创建独立真实目录、核验、更新unit路径、重启并验证，不能用cp -a复制current符号链接。

## 部署异常与处理

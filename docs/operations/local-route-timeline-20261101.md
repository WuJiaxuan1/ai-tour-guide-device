# 本地导航式路线列表

- 官方路线详情、已规划专属路线和游览进度共用 RouteTimeline。
- 使用每次停靠的 stopId/stop_id，保留同门往返和重复经过，不按地点去重。
- 规划前仍可编辑景点；规划后直接显示实际顺序，编辑区折叠，停留设置可从线路节点打开。
- 起终点使用箭头/旗帜；已到访勾号、下一站高亮、跳过标记由服务端状态决定。
